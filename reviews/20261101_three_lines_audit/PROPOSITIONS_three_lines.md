## 0 为什么 0/100 采纳不代表理论失败

第五节要纠正一个检验方式的错配，先在这里说清：

- **性能命题**问："把 S1/S2/S3 接进求解器，解会不会更好？" → 实测 0/100 采纳。
- **预测命题**问："在什么条件下，重构的代价高于功率补偿？" → 0/100 采纳是它成立的**证据**。

用性能命题去检验预测命题，会把阳性结果读成阴性结果。要把它变成证据，必须补一步**反事实审计**（§6.2）：把被拒候选在真值信道上重新打分，确认"拒绝"确实是对的。这一步不做，0/100 就只是"没效果"；做了，它就是"判据正确 100 次"。

## 1 主线一：从估计界到决策输入

### 1.1 已成立的部分（不作创新声明）

观测环节的经典 CRLB 与匹配滤波可达性：`r = √E_p·h + w`，`Var(w)=N0` ⇒ `Var(h̃) ≥ N0/E_p`，为确定性参数下复高斯观测的经典界，匹配滤波恰好达到。数值见[基础层_CRLB的作用与适用边界](../../代码/基础层_通信与信道估计_20261023/results/crlb_role_n10.json)：2 W / 20 µs 时近端 4.6×10⁻⁴ dB，全部 90 条候选 p50 = 1.4×10⁻² dB，最差 5.8×10⁻² dB。

**结论**：在 10/50/100 车规模下观测环节不是瓶颈。这一条是**前提**，不是贡献。

### 1.2 命题 1（分位数校准桥）

设块平均速率 `R̄` 在给定信息 ℐ 下服从均值为 μ 的尺度族分布，`R̄ = μ + σZ`，`Z` 零均值单位方差、`F_Z` 为其分布函数。名义 ε 分位为 `Q_ε = μ + σ z_ε`，其中 `z_ε = F_Z⁻¹(ε) < 0`（ε<0.5）。

决策使用的是方差被**低估**的近似 `σ̂ < σ`，得到 `Q̂_ε = μ + σ̂ z_ε`。

**命题**：
1. `Pr{R̄ < Q̂_ε} > ε`，即名义 ε 分位被实际违反得比 ε 更频繁；
2. 违反概率 `c(σ̂/σ) := Pr{R̄ < Q̂_ε}` 关于比值 `σ̂/σ` **严格单调递增**。

**证明**：
`Pr{R̄ < Q̂_ε} = Pr{μ + σZ < μ + σ̂ z_ε} = Pr{Z < (σ̂/σ) z_ε} = F_Z((σ̂/σ) z_ε)`。
因 `z_ε < 0`，`σ̂<σ` ⇒ `(σ̂/σ)z_ε > z_ε` ⇒ `F_Z((σ̂/σ)z_ε) > F_Z(z_ε) = ε`，得 (1)。
`F_Z` 严格单调 ⇒ `c` 关于 `σ̂/σ` 严格单调递增，得 (2)。 ∎

**推论 1.1（α 的存在唯一性与可解性）**：定义保守化算子
`R̃(α) = μ·(Q_ε/μ)^α`（即代码 `inflate_low`，α>0）。
因 `Q_ε<μ`，`α` 增大 ⇒ `R̃(α)` 单调递减 ⇒ 违反概率单调递减。故集合
`A = {α>0 : Pr{R̄ < R̃(α)} ≤ ε}`
是以某 `α*` 为下界的区间，`α*` 存在且唯一。

**意义**：`α` 不是拍出来的经验参数，而是**由覆盖率反解的校准量**。现有实现固定 α=1.35，只有一句"实测后验 sd 约为真实误差 sd 的一半"作为依据；命题 1 把它变成一条可算的曲线：给定 α，测覆盖率，二分到 `α*`。

### 1.3 实测回填（2026-11-01，`e5_D_chance_d010_20261031h`，999 块 / 9990 条链路）

脚本：`代码/分析_三条主线_20261101/diagnose_three_lines.py --part calib`。

| α | 实际跌破率 | 与名义 5% 的比 |
|---:|---:|---:|
| **1.00**（未校准） | **10.27%** | **2.05×** |
| 1.35（现行实现） | 4.58% | 0.92× |
| 1.60 | 2.53% | 0.51× |
| 2.00 | 1.01% | 0.20× |
| **α\*（二分反解）** | **5.00%** | 1.00× |

**结论有三条，都要写进论文：**

1. **命题 1 得到确认，而且量级不小。** 预测器的名义 5% 分位被实际跌破 **10.27%**，是名义值的 **2.05 倍**。这不是"估计器不好"，而是预测方差被系统性低估——正是命题 1 的结论。
2. **推论 1.1 得到确认，α 可解。** `α* = 1.300`，而代码里实现的是 **1.35**，两者相差 4%，方向偏保守（4.58% < 5%）。
3. **因此 α 不是"拍出来的数"，也不是把门弄坏的原因。** 这一条推翻了一个常见猜测：机会约束过严不是因为 α 太大。α=1.35 对应的实际可靠性是 **95.4%**，与设计意图一致。

> **⚠ 分层陷阱（必须写进限制）**：按 `csi_age_s` 分层看起来"年龄越大越差"，但实测是 `age<5ms` 违约率 10.73%、`5–50ms` 8.96%、`50–100ms` 9.10%——**年龄越大反而越好**。原因是这批数据里 `csi_age` 被**模式**完全决定：RF 导频周期 1 ms（n=7347，全部 age<5 ms），VLC 导频周期 50 ms（n=2643，age 5–50 ms）。RF 违约率 10.73%、VLC 9.00%，与"年龄分层"是同一批样本。
> **所以这版数据不能用来分离"年龄"与"模式"的影响。** 要分离必须固定模式、只改导频周期（`plot_estimation.py --rf-period`），基础层已有的 1 ms vs 20 ms 对照正是这么做的（3.70 dB → 5.27 dB）。

**已被数据支持的部分**（同目录 `基础层_CRLB的作用与适用边界` §3.3）：
- 复合 AR(1) 标称 90% 区间，实际覆盖 **84.7%–85.8%**（低估方差 ⇒ 覆盖不足，与命题 1(1) 同向）；
- 两状态估计器实际覆盖 **88.9%–89.2%**（方差设定更接近真实 ⇒ 覆盖接近名义）。

这是把命题 1 从"显然"变成"已发生"的直接证据。

### 1.4 边界（必须写进论文）

- 命题 1 只对**尺度族 + 同均值**成立。跨模型（如均值也偏）时需另加一阶项，不能直接套。
- CRLB 是**下界**，不是误差上界、不是置信半径、不能乘系数当安全裕量。`Var ≥ N0/E_p` 与"实际误差 ≤ k·CRLB"没有任何蕴含关系。
- 两状态 RF 模型是非线性的，**严格 PCRB 尚未推导**（原文档已撤回"已到界"表述）。因此"估计器已达最优"不能作为论文结论。

## 2 主线二：可靠服务资源代价与切换条件

这是三条主线里唯一能给出**结构性定理**的地方。先给它一个合适的评价对象：

> **定义（单链路服务功率成本）** 链路 ℓ 在给定他人功率下的**服务功率成本**为
> `C_ℓ := P_{c,ℓ} + p^svc_ℓ`，
> 其中 `P_{c,ℓ}` 是该模式静态电耗（RF 0.1159 W / VLC 1.745 W），`p^svc_ℓ` 是使块平均速率达到门限 `q` 的**最小电输入功率**。

`C_ℓ` 就是"S1 探针"算出来的那个量：`p^svc` 对应 `weak_link.json` 的 `p_star`，`P_c` 来自 `p3base/config.py`。**它现在已经被记录下来了，只是从来没被当作判据使用。**

### 2.1 单链路能效的形状（引理，两种 SINR 口径都成立）

固定匹配、固定其余链路功率，链路 ℓ 的 `SINR = ζ p`（RF 线性口径）或 `SINR = ζ p²`（VLC 平方律口径），`ζ>0` 只依赖几何、增益、干扰与噪声；`r = B log₂(1+SINR)`；`EE = r/(P_c+p)`。

**引理 1（单峰性）**：`EE(p)` 在 `(0,∞)` 上严格单峰。

**证明（线性口径）**：`d/dp [B log₂(1+ζp)/(P_c+p)]` 的符号等于
`g(p) := ζ(P_c+p)/(1+ζp) − ln(1+ζp)`。
`g(0) = ζP_c > 0`；`g(∞) = −∞`；且
`g'(p) = −ζ²(P_c+p)/(1+ζp)² < 0`，
故 `g` 严格递减，唯一零点 `p^EE`，`EE` 在 `(0,p^EE)` 增、`(p^EE,∞)` 减。

**证明（平方律口径）**：此时
`g(p) := 2ζp(P_c+p)/(1+ζp²) − ln(1+ζp²)`，
`g(0)=0`，`g(∞)=−∞`，且
`g'(p) = 2ζ(P_c+p)(1−ζp²)/(1+ζp²)²`，
其符号由 `(1−ζp²)` 决定，**只在 `p = 1/√ζ` 变号一次**（由正转负）。故 `g` 先增后减；又 `g(0)=0`、`g'(0)=2ζP_c>0` ⇒ `g>0` 于 `(0,·)` 起、终于 `−∞` ⇒ 唯一零点 `p^EE`，单峰。 ∎

**注**：平方律口径下的 `p^EE > 1/√ζ`，即最优点落在"SINR 过 0 dB"之后——这与 RF 线性口径不同，是 VLC 的 `SINR∝p²` 直接导致的。写论文时不能把两种模式的最优功率做成同一个公式。

**推论 2.1（服务功率的闭式）**：令 `γ_q = 2^{q/B} − 1`，则
`p^svc = γ_q/ζ`（线性）或 `p^svc = √(γ_q/ζ)`（平方律）。

两者都与 `D` 成正比：**干扰越大（`ζ` 越小）服务功率越高**。这是"干扰耦合放大服务代价"的最简形式。

### 2.2 命题 2（瓶颈钉住定理）

记块内最低链路能效 `Ψ(p) = min_k EE_k(p)`，最弱链路为 `k*`。

**命题 2**：设 (i) 匹配与其余链路功率固定；(ii) `p^EE_{k*} < p^svc_{k*}`。则
1. 在可行集 `[p^svc_{k*}, P_max]` 上 `EE_{k*}` **严格递减**，故
   `max_{p ≥ p^svc} EE_{k*} = EE_{k*}(p^svc_{k*})`，最优解落在 **QoS 边界**上；
2. 任何提高 `p_{k*}` 的动作都不能提高 `Ψ`；
3. 提高 `p_{k*}` 还会通过同模式干扰降低其余链路能效，因此是**双向不利**。

**证明**：(1) 由引理 1 与 (ii) 直接得；(2) `Ψ ≤ EE_{k*}`，而 `EE_{k*}` 在可行方向上不增；(3) `D_j` 对 `p_{k*}` 单调增（同模式分母含 `p_{k*}`），`r_j` 对 `D_j` 单调减，故 `EE_j` 单调减。 ∎

**推论 2.2（可改进方向的唯一性）**：在命题 2 的条件下，能提高 `Ψ` 的动作只有两类：
- **A′ 削峰**：降低**其他**同模式链路的功率，减少 `k*` 所受干扰 ⇒ 抬高 `EE_{k*}(p^svc)`。代价是那些链路自身 EE 下降 ⇒ 均 EE 下降，受 `(1−δ)η_ref` 约束。
- **B′ 重构**：改变 `k*` 的接收端或模式，使 `k*` 换一条增益/干扰更好的链路。

**"抬最弱链路自己的功率"不在可改进方向里**——这正是候选 A 被 QoS 门拒 70/100 次的机制解释。

**与实测的对应**（待独立复核）：

| 命题预测 | 实测量 |
|---|---|
| `p^EE < p^svc` 的块占多数 | 95/100 块 `p_{k*} > p^svc`，其中 **70 块** `p^EE < p^svc` |
| 候选 A（抬到 `p^EE`）主要被 **QoS 门**拒 | A 被 QoS 门拒 **70** 次 |
| 削峰（refine）是有效方向，但受 δ 限制 | refine 把 min EE 抬 +20%~+24%，代价 −1.4%~−2.0% 均 EE（10 s）；100 s 上 +45.0% / −5.3% |

**70 这个数与候选 A 的 QoS 门拒绝次数完全重合，不是巧合**：它既是命题 2 的前提被满足的块数，也是"抬功率这个方向不可行"的块数。

### 2.3 命题 3（切换代价判据）

**命题 3a（跨模式、耦合可忽略）**：设链路 ℓ 从模式 m 切到 m′，切换后 QoS 仍为有效的 `r=r'=q`，且 **ℓ 对其他链路 `D_j` 的影响可忽略**。则
`EE_{ℓ'} > EE_ℓ ⟺ C_{ℓ'} < C_ℓ`，
即 `P_{c,ℓ'} + p'^svc_{ℓ'} < P_{c,ℓ} + p^svc_ℓ`。

**证明**：同等 QoS 下 `r'=r=q`，故 `EE' > EE ⟺ q/(P_c'+p') > q/(P_c+p) ⟺` 分母更小。 ∎

**这是本文"切换充分条件"的封闭形式**，且它把 S1 从"探针"变成"判据的输入"：`p^svc` 就是 `p_star`。判据不需要跑任何优化，只需 `P_c` 与 `p^svc`。

**命题 3b（同模式换接收端，含耦合）**：换接收端保持模式不变，于是 `D_j` 对同模式邻居改变。此时 3a 的闭式失效，至少需加一阶修正：
`ΔEE_j ≈ (∂EE_j/∂p_ℓ)·Δp_ℓ`，
其中 `∂EE_j/∂p_ℓ` 在代码里就是 `interference_sensitivity` 输出的 `sens`。

**因此 S2 的正确定位是"给切换判据提供一阶修正项"，而不是"排序该降谁的功率"。** 后者是削峰（A′），由 refine 用连续优化做得更好；前者是 3a 无法覆盖的部分，是 S2 唯一有独占价值的位置。

### 2.4 命题 4（S2 的定义域不含切换）

**命题 4**：设配置写成 `(M, p)`，`M` 为匹配与模式的离散结构。`∂EE_j/∂p_c` 只在 `M` 固定时可定义。切换改变 `M`（干扰图的连边集合改变），是离散跳变，不存在使 `ΔEE ≈ ⟨g, Δ(M,p)⟩` 对所有切换一致成立的梯度 `g`。

**推论 4.1**：S2（一阶敏感度）在结构上**无法评价切换**，其天花板不是调参问题。
**推论 4.2（解释空排序）**：当最弱链路在网内没有同模式邻居时，`sens` 除自身列外全为零，排序集为空。实测 28 块排序为空、`sens` 只有一个非零列（见 `weak_link.json` block 2：`sens=[554924,0,0,0,0]`、`ranking=[]`）。

**这一条把"模块调不好"变成了"结构性结论"**，并且是可写进论文的正面结果：在 RF/VLC 分频段模型中，跨模式切换**不产生任何干扰重排收益**，其收益只能来自链路增益与静态功耗；因此 S2 的作用域被物理口径限死。

### 2.5 命题 5（无耦合时"重构优于补偿"的判据）

**命题 5**：在命题 2 的条件下（`p^EE_{k*} < p^svc_{k*}`），若存在合法替代链路 ℓ′ 使 `C_{ℓ'} < C_{k*}`，则重构 `k* → ℓ′` 在**单链路**能效上严格优于任何仅调整 `k*` 功率的方案。

**证明**：命题 2 给出"仅调功率"的上界 `EE_{k*}(p^svc_{k*}) = q/C_{k*}`；命题 3a 的论证给出 `EE_{ℓ'}(p'^svc_{ℓ'}) = q/C_{ℓ'}`。由 `C_{ℓ'}<C_{k*}` 即得严格大于。 ∎

**但注意**：单链路判据**不是**全局判据。重构会改变其他链路的干扰与匹配，均 EE 可能跌破 `(1−δ)η_ref`，于是被预算门拒——这正是"命题 5 成立但采纳仍为 0"的情形。所以完整判据是**两级**：

> **两级切换判据**
> 第一级（单链路，闭式）：`C_{ℓ′} < C_{k*}` —— 命题 3a/5；
> 第二级（全网，预算）：`Φ(M', p') ≥ (1−δ)·Φ(M, p)` —— 均能效预算门。

**0/100 采纳的正确读法是：第一级可能大量通过，第二级几乎全部拒绝。** 这正好解释为什么放开 δ 到 0.20 会出现 3 次采纳，且三条全是 B/C 类。

### 2.6 这一节的边界

1. 命题 3a 的"耦合可忽略"是**条件**，不是假设掉。它的可检验形式是 ℓ 的干扰份额
   `s_ℓ := (∂D_j/∂p_ℓ)·p_ℓ / D_j`。`s_ℓ` 大时 3a 只是近似，必须报 3b 的修正量。
2. 命题 2 只在**固定匹配**下成立。跨匹配时 `p^svc` 与 `p^EE` 都变，不能把两种模式的 `p^svc` 直接比较。
3. 以上全部是**单块、预测口径**的结果。真实信道上的兑现率必须另行统计（100 s 上真值超预算 20.8% 就是这个差距）。

## 3 主线三：候选评价与联合更新

### 3.1 命题 6（排序有效性，以统计量表述）

对同一块的一批候选，设精确排序为 π（按真值或完整重优化的 min EE），代理排序为 π̂。定义
- 符号正确率 `s = Pr{sign(Ĝ_i − Ĝ_j) = sign(G_i − G_j)}`；
- top-k 覆盖率 `κ_k = |top_k(π̂) ∩ top_k(π)| / k`。

**命题 6（可检验，非定理）**：在冻结信息与历史快照上，`κ_k ≥ 1 − 2(1−s)`。
（这是排序统计的标准界：符号误判率 s 决定 top-k 的最大漏检比例。证明：每次误判最多使一个元素离开 top-k。）

**用途**：它把"代理评分有用"从口号变成可报的数（s、κ_k、净收益符号误判率）。**必须同时报漏检**，不能只报被自己选中的候选，否则无法估计评分准确度（原方案 §7 末段已要求）。

### 3.2 命题 7（接受次数界）

若每次接受都使目标 `Ψ` 严格增加至少 τ>0，且 `Ψ` 有界于 `[0, Ψ_max]`，则有限候选 + 联合邻域更新的接受次数不超过 `(Ψ_max − Ψ_0)/τ`。

**证明**：单调递增数列在紧区间内，最小步长 τ ⇒ 项数有限。 ∎

**这不是收敛性证明**：它只给"接受次数有界"，不给"收敛到局部最优"，也不给变量收敛。原方案 §6 表格里已写明这一区别，不能合并。

### 3.3 这一节的边界

- 代理评分（`_proxy_scores`、`_equ_sinr_scores`）是**启发式初值**，不是 S2 的资源代价。论文里不能写"代价引导的安全剪枝"。
- `b_S, b_E` 的误差界**未推导**，所以不能写"认证收益"。

### 8.1 已确认的复现性缺陷：v5 归档无法用当前启动脚本复现

这是本轮**独立发现**的问题，比审计结论本身更早可用。

| 量 | 值 |
|---|---|
| block 2 的 `reference.eta_ref`（归档记录） | **445.884 161 M** |

**根因**：
- 归档 `summary.json` 记录 `config.physical.vlc.sinr_model = "square_law"`；
- 当前 `p3base/config.py` 的默认值是 `"linear"`；

> **这条要写进项目的验收规则**：`source_sha256` 通过只证明**源码**没变，不证明**启动命令与配置**没变。归档必须同时保存完整的命令行（v5 的 `summary.json` 记了 config 但没记 argv），否则复现性是无法恢复的。

### 8.3 命题 2 被实测否证，但换来了一个更强的替代命题

100 块全部通过复现校验（`mismatch=-`，0 排除）后，逐块计算最弱链路的三个功率：

| 量 | 定义 | 中位数 / 计数 |
|---|---|---|
| `p_svc` | S1 服务功率（满足 1 Mbit/s 的最小电功率） | — |
| `p_cur` | 当前执行动作在该链路上的功率 | `p_cur / p_svc` 中位 **8.26** |
| `p_ee` | 该链路自身能效峰值功率（`link_ee_optimum`） | `p_ee / p_svc` 中位 **10.96** |

**结果：**

| 判据 | 计数 |
|---|---|
| `p_ee < p_svc`（命题 2 的前提） | **0 / 100** |
| `p_cur > p_svc`（功率高于服务功率） | **95 / 100** |
| `p_cur < p_ee` | 60 / 100 |
| `p_cur > p_ee` | 40 / 100 |
| **`p_cur / p_ee`** | 中位 **0.98** |

**结论一（否证）**：命题 2 的前提"自身能效峰值低于服务功率"在 100 块里**一次都没出现**，
所以"瓶颈被 QoS 钉住"不是本场景的机制。这条必须从论文里删掉——它是我根据
候选 A 被 QoS 门拒 70 次的**反向推断**，实测不成立。

**结论二（替代命题，更强）**：`p_cur / p_ee` 的中位是 **0.98**，即**当前解已经把最弱链路的
功率放在它自身能效峰值的 2% 以内**（60 块在峰值下方、40 块在上方，正好跨在峰值两侧）。

于是正确的结构性陈述是**峰值钉住**而不是 QoS 钉住：

> **命题 2′（峰值钉住）** 设最弱链路 `k*` 的功率已落在其自身能效峰值附近
> （`p_cur ≈ p_ee`，实测中位比 0.98）。则由引理 1 的单峰性，沿 `p_{k*}` **任意方向**移动
> 都会降低 `EE_{k*}`：向下偏离峰值、向上也偏离峰值。因此提高瓶颈能效**不能**通过调整
> `k*` 自身的功率实现，只能（i）降低其他同模式链路的功率以减少干扰，或（ii）改变 `k*` 的链路。

这个版本不需要 `p_ee < p_svc` 这个从不成立的假设，而且它同时解释了两件事：
候选 A（把功率抬到 `p_ee`）的真值收益中位只有 **−0.20%**（它已经在峰值上），
以及 S2/C 类候选才是唯一可能有效的方向。

**与外部说法的不一致（需记录）**：外部复核曾报"95/100 块当前功率已高于服务功率，其中
**70 块**自身 EE 峰值又落在服务功率之下"。前半句与我的测量一致（95/100），
**后半句无法复现**（我得到 0/100）。两者用的是同名函数（`service_power_probe` /
`link_ee_optimum`），差异只可能来自"最弱链路"的选取口径。论文引用前必须统一这个口径。

### 8.4 判决：334 个候选全部被拒是**正确**的

1. **守卫基本无损。** 每一族的真值 Δmin 中位数都 **≤ 0**，即被拒候选平均比执行动作**更差**。
2. **A 候选是一个"空操作"。** 真值 Δmin 中位 **−0.00%**，且 **15/100 块逐位相同**（|Δ|<1e-6）。
   这正是命题 2′（峰值钉住）的直接证据：抬到 `p_ee` 什么也没改变，因为**它已经在 `p_ee` 上**。
3. **B 候选被正确淘汰的程度最高**（−97.71%，只有 6/102 更好）——换接收端会破坏匹配质量，
   守卫挡掉它是对的。C 与 S2 同样是多数更差。
4. **预测排序是有信息量的**：候选内 Kendall τ 均值 **+0.358**，68%（45/66）的块为正相关。
   这支持命题 6（排序有效性可度量），但也说明它只是"部分相关"，不足以代替真值复核。

**残余空间有多大**：100 块中有 **28 块**存在"真值更优**且**真值仍在 δ 预算内"的被拒候选，
但若强制采纳其中最好的一个，min EE 的**中位增益只有 +0.02%**，仅 **1 块**超过 10%
（28 块里 24 块是 A，属噪声级）。**结论：精修 + 守卫几乎没有丢性能。**

**"全都采纳"对照（回应用户提出的反向思路）**：把每块预测 min EE 最高的候选强制采纳，
结果为 **35/100 块真值更优，但均 EE 中位 −1.96%，且只有 47% 的块真值仍在预算内**。
**所以"全都采纳"比守卫差**——守卫的价值是实测出来的，不是假设的。

### 8.5 对 §5.2 的最终更正

我在 §5.2 曾把 0 采纳归因为"精修抢先"，方向对，但当时给的量级（79% 块存在 +87.9% 的更好候选）
**是我口径用错导致的假象**（用了 `rate/p` 而非 `rate/(P_c+p)`）。正确量级是
**28% 的块、+0.02% 中位增益**。结论从"精修支配但有代价"收紧为
**"精修 + 守卫在预算门内已接近该候选集的上限，离散重构无增量"**。

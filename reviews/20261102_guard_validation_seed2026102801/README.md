## 3 为什么没通过：**卡在目标上，不是卡在预算上**

这是本轮最重要的诊断，也是它否决 Guard-v2 的原因。

对**所有"真值更优且真值 QoS、真值预算都通过"的候选**（即真正值得采纳的那些），逐块取最好一个：

| 量 | 设计种子 | 验证种子 |
|---|---:|---:|
| 合法改进块 | 29 | 33 |
| 其最佳候选的**预测 Δmin 中位** | −0.00% | **−0.00%** |
| 其**预测 Δmin > 0** 的个数 | **2 / 29** | **1 / 33** |
| 其**预算概率** `P(G≥0)` 中位 | **1.000** | **1.000** |
| 其真值 Δmin 中位 | +0.01% | +0.05% |

**两条种子给出同一个事实：**

> 真正值得采纳的候选，**预测器认为它们的预算没有问题（P(G≥0) 中位 = 1.000）**，
> 但**不认为它们的 min EE 更好（预测 Δmin 中位 −0.00%，只有 1–2 个为正）**。
> 也就是说：**挡它们的是"预测 min EE 不占优"，不是"预算门"。**

于是：

1. **ρ（预算机会约束）作用在错误的约束上**——它想放宽的那道门，这些候选本来就能过。
2. Block 23 之所以看起来像"预算门问题"，是因为它是**预测精度上的离群点**：
   预测 +333.98%、真值 +334.30%，同时预算差 0.33%。两条信道上都只出现一次。
3. 其余"合法改进"的真值幅度是噪声级（中位 +0.01% / +0.05%，p90 +6.0% / +14.4%），
   **没有可重复的大收益可救**。

### 验证种子的合法改进分布（对照）

| 量 | 值 |
|---|---|
| 合法改进块 | **33 / 100** |
| 真值 Δmin 中位 / 均值 / p90 | +0.05% / +3.13% / +14.44% |
| >10% / >50% | **5** / 0 |
| 最大单块 | **+26.7%**（block 90 `S2_cut1`） |

对比设计种子：29 块、中位 +0.01%、p90 +6.03%、>10% 仅 1 块（Block 23, +334.3%）。

> **解读**：验证种子有**更多**中等幅度（>10%）的合法改进（5 vs 1），但**没有**任何 +334% 级别的极端案例。
> 而 ρ 规则在设计种子上唯一"起作用"的那一次，恰恰靠的就是那个极端案例。
> **规则抓住的是离群点，不是机制。**

## 4 结论与对论文的影响

### 4.1 判决

按预登记标准：**停止 Guard-v2 改造方向。**

- 不实现任何 Guard 变体；
- 保留现有硬预算门（它在两条信道上都是"典型无损"的：各族真值 Δmin 中位 ≤ 0）；
- **Block 23 改写成局限案例**，措辞按外部复核意见：
  > "**预测器准确识别了该候选的瓶颈改善**（预测 +333.98%、真值 +334.30%），是**预测预算硬门**（短缺 0.33%）拒绝的；
  > 针对该案例设计的概率门调整未能在第二个信道种子上复现收益——属于**个体案例不可复现**，不是预测能力不足。"

### 4.2 这一轮真正得到的两个可写结论

1. **预算余量的预测分布是标定的**（两条种子：sd(z) 1.033 / 1.062，95% 覆盖 94.9% / 93.9%）。
   这是正面结果，可用于**主线一**（不确定性被正确量化），且它否决了"用更复杂模型重建干扰图"的路线。
2. **候选修复层的收益上限是噪声级**（两条种子的合法改进中位 +0.01% / +0.05%）。
   这是负面结果，但它**如实界定了主线三**：排序可用（τ=+0.913）、守卫无损、**但可获得的增量极小**。

### 4.3 与 S1/S2/S3 的关系（独立结论，见 `s1s2s3_audit.py`）

另一条独立证据（只读归档，与种子无关）：**`p_svc` 在 96.8% 的链路上贴功率下界**，
导致命题 3a 的代价判据 `C_ℓ = P_c + p_svc` 在同模式内**完全不可分辨**（86/100 块存在 <1% 并列）。
**这解释了为什么 S1/S2/S3 无法驱动一个有效的 S3 判据——不是没实现，是本模型下判据退化。**

## 5 边界（不得越过）

1. **两个种子、每个 100 块**。有效改进本身只有几十块，大收益只有 1 个。**不足以建立普遍结论。**
2. 本验证**只针对 Guard（预算判定）**，不检验主算法（reference + refine）的优劣。
3. `scan` 与 `replay` 在本种子上逐项相同，**不能因此说两种口径等价**（设计种子上 ρ=0.9 就不同）。
4. 未做 50/100 车、未换 SUMO 轨迹。
5. `2026102801` 在 v4 用过（见 §1 披露）。

这是实际源码归类，不是将“真实信道”和“估计信道”混成一份输入。决策只能用当时可获得的观测/后验，真值用于执行评价。

## 估计数据怎样读

估计曲线CSV含 `time_s`、RF/VLC真值、估计、区间、观测时间、观测值、可见性和端口。`*_obs_time_s` 与当前 `time_s` 不一定相同，不能直接把陈旧观测误差当同期测量噪声。文件名 two_state 表示双状态版本；未带该后缀的文件是旧对照。

CRLB校验中的MSE/CRLB约1来自特定合成高斯子问题；不等于完整双状态后验/未来服务达界。CRLB是方差下界，不能当保守误差上界。14%/86%的旧置零方差实验尚非严格全方差分解，见 reviews 与 research_history/ERROR_LEDGER.md。

该目录目前没有50/100完整信道估计正式结果，不复制10车结果改名。

## 与资源分配的接口（2026-10-27 补充）

本模块的价值不能只由估计 MSE 或"比原始观测好多少 dB"来评价。整条链路是：

```
估计器输出（均值＋协方差）
   → forecast.py 条件轨迹库（块内未来衰落抽样）
   → 候选动作的块平均速率条件分布
   → 下侧分位  R_low = Q_0.05(R̄ | I_b, a_b)
   → 资源分配约束：R_low ≥ 1 Mbit/s
   → 真实执行后的 EE、最低 EE、违约
```

三点接口约定：

1. **只有"预测分布有效"时，下分位才有概率解释**。32 条轨迹样本下，5% 尾部只对应
   最靠后的 1–2 条样本；经验分位不等于真实 95%。
2. **估计器的增量价值要在资源分配层测**，不是在本模块里测。同一真实信道、同一求解
   预算下，只改决策可用的信息（观测 / 均值 / 均值＋方差 / 校准分位），看真实违约与
   EE 怎么变。现有证据见 `plans/研究主线与实验矩阵_20261027.md` §3。
3. **CRLB 只是方差下界**，不进入该链条的任何一步作为约束；它回答"估计精度极限"，
   不回答"未来块平均速率有多可靠"。

需要单独核对的一个量：`forecast.py` 传给分配器的方差是**块初后验方差**（认知不确定性），
与块内未来衰落方差（偶然不确定性）是两项，当前机会约束把它们合在一起按 32 次抽样
体现。若要分开报告，必须显式说明，不能默认二者可加。

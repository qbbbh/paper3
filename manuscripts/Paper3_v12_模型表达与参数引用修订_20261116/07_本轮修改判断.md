# 本轮修改判断

这轮修改集中在系统模型、信道估计及仿真设置。结果分析沿用V11，六组图与逐图数据未改动。完整修改见[逐段对照](03_逐段修改前后与理由.md)。

| 用户指出的问题 | 本轮采用的修改 | 保留的必要区别 |
|---|---|---|
| 距离、频率单位的文字累赘 | 正文直接定义车辆间距离和RF载波频率；单位归一化写入式（3） | 经验路径损耗的常数要求特定单位，不能删除后让任意单位直接代入。1 m计算下限集中列于附录A。 |
| 式（8）定义功率后未使用 | 上标统一为RF/VLC，式（9）、（10）直接复用式（8） | 优化变量p按发送支路电输入定义一次，后文简称发射功率；输出功率仍经转换效率得到。 |
| gRF和hRF是否重复 | 删去几何增益简称gRF,geom，用路径损耗直接表示；说明gRF与hRF的平方模关系 | 功率增益与归一化复幅度不是同一个量，CRLB的估计对象不改变。 |
| 模式、方式与搜索不清楚 | RF/VLC称通信方式；车辆配对、发送方向及RF/VLC选择合称通信模式。第四节直接列出要调整的对象 | 当前离散决策包括配对和方向，不能缩成固定车辆之间的RF/VLC二选一。 |
| 引用教材章节、阴影参数位置靠后 | 两条教材替换为2024、2023年期刊论文；阴影平稳标准差移到状态递推之前 | 重复引用旧编号本身不是错误。本轮前移是为了把同一物理量的定义与来源放在一起。 |
| 可观测条件与“相关性”难懂 | 说明VLC接收光过弱时不更新，并明确相关的是观测时刻与决策时刻的信道状态 | 有效导频条件和方差传播条件影响数学含义，改清楚而不删掉。 |
| 参数表后像换算记录 | 保留关键噪声数值，删除重复结论；换算、限幅与滤波差异列入正式附录A | 所有迁出内容在论文内部可查，不再依赖缺失的外部说明。 |
| 表格缺少出处、名称太长 | 增补已核引用，改为“转换效率”“发射功率范围”；观测表补σ0 | 对RF100 m和VLC0.25分别说明场景选择与工作点近似，不伪装成同一设备的直接测量。 |

本轮实际阅读了Qin等2025年AEU论文的系统模型与仿真参数段、刘思佳学位论文的模型章，以及桑军学位论文的通信模型与结果段。采用的是先定义车辆与物理量、再衔接接收信号和干扰的组织方式，没有搬用旧论文的信道假设。引言前两段的作者原有论证保持。

复核时发现并修正了两处压缩风险：阴影标准差补回“平稳”；状态方程与RF滤波系数分别回引，避免把时间常数限幅后不完全相同的系数说成相同。式（16）的代数简化、式（8）—（10）的功率替换均保持原模型。

该版本没有新增仿真，没有改变模型参数、优化目标、参考能效、统计集合或方法排名。新增文献为既有取值补充依据，不反向宣称冻结实验当时已经使用了这些新文献。

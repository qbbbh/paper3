# 从作者逐句修改中学习：引言写作的核心理念

日期：2026-11-09。

依据：作者对Paper3引言的逐句修改、对v12的后续追问，以及作者提供的Paper6师生讨论记录。本文归纳的是判断标准，不是让所有论文照搬同一个开头或句式。示例改句用于解释原则，不表示每一句都已由作者逐字定稿。

## 一、最核心的要求

**用准确、具体、连贯的语言，让读者明白：问题为什么存在，现有方法解决到哪里，本文为什么这样做，以及这项工作好在哪里。**

作者反复追问“这个词是什么意思”“为什么需要这一步”“这个性能后面分析了吗”，是在要求写作者承担解释责任。读者不应依靠读过代码、了解聊天历史，才能理解引言。

这同时涉及语言、科学概念和论证结构。仅把长句改短、把中文词换成英文术语，并不能完成这种修改。

## 二、八条核心理念

### 1. 每句话都要提供信息，承担明确任务

“V2V通信支持车辆间的信息交换”几乎用后半句重复前半句，没有说明为什么值得研究。开篇应交代应用价值，再介绍与本文有关的技术特点，让读者逐步进入问题。

“车用通信是智能交通系统的重要组成部分”在这里承担开场定位作用；它不是所有论文必须使用的固定首句。背景不必新奇，但应简洁，并尽快进入具体研究。

检查办法：删掉这句话，读者会失去哪条必要信息？如果没有损失，考虑删除或合并。已经准确简洁的句子则保持稳定，不为了体现工作量反复改写。

### 2. 先说具体对象，再使用专业概括

作者反对“配置”“资源评价”“效率收益”“这种互补能力”等模糊表达，因为读者无法判断它们具体指什么。

引言优先写通信模式、发射功率、接收信号、其他车辆的干扰、传输速率等具体对象。需要使用简称或抽象概念时，先建立其含义。

例如，在动机段先说“车辆运动会改变接收信号强度以及其他车辆产生的干扰”，比直接写“改变期望链路和交叉干扰信道”更容易说明物理影响。后者可以在模型部分准确定义后使用。

检查办法：对于“该配置”“这种能力”“上述机制”，读者能否马上指出它是什么？新名词是否对应具体变量、动作、信息或性能？

### 3. 统一术语，同时分清不同概念

作者既要求统一名称，也反对用“信道不确定性”笼统包住不同现象。这说明术语统一需要以概念清楚为前提。

| 对象 | 准确写法 |
|---|---|
| 对应时刻的估计与真实信道不一致 | 信道估计误差 |
| 获取信息后信道继续变化 | CSI过时，并交代移动、衰落等原因 |
| 信道随时间变化这一现象 | 动态信道或信道变化 |
| 最大化最弱链路的能效 | Max-Min EE优化目标 |
| 被评价的最小能效数值 | 最低链路EE |
| 预先规定的通信质量要求 | 固定最低速率门限 |
| 随观测和资源动作变化的预测量 | 预测速率下分位数 |

“通信模式和发射功率”是本文的统一变量表述。按照本文约定，通信模式含通信车辆及RF/VLC方式的选择；建模时仍需准确展开，不能靠改名删掉数学含义。

检查办法：同一个对象有没有随意换名？不同对象有没有混用同一个名称？这个量是固定门限、变化的预测值、决策变量，还是评价指标？

### 4. 写清原因、影响和方法之间的关系

作者要求在“车辆运动导致接收功率变化”之后，说明它对通信的影响；提出预测方法之前，解释已有CSI为什么不足以描述随后通信。

本文的动机可以顺着以下关系推进：

> 车辆移动和衰落改变信号与干扰 → 已有CSI不能完全描述后续状态 → 通信模式和功率选择受到影响 → 需要利用已有观测预测通信周期内的传输速率。

公平性也要说明原因：高EE链路能够抬高平均值，因此平均EE提高不意味着低EE链路同时改善。由此引出最低链路EE及平均EE下降比例约束。

推理强度要准确：上面的关系不能扩大成“平均EE优化一定损害弱链路”；实验相关现象也不能直接写成唯一因果解释。

检查办法：“因此”“从而”“为此”前后是否存在真正的逻辑关系？是否省略了必须由读者猜测的一步？

### 5. 每段只承担一个主要任务，段间推进问题

作者指出第一段末尾应引出资源分配，第二段再讨论CSI如何影响它。这是段落功能安排：上一段建立下一段讨论的对象。

当前前三段分工如下：

1. RF/VLC具有互补特点，需要联合选择通信模式和发射功率。
2. 估计误差与后续信道变化影响资源选择，需要预测传输速率与干扰。
3. 提高平均EE还不足以改善低EE链路，需要明确的效率与公平取舍。

第三段不必再完整讲一遍干扰，也不必提前给出所有EE数学定义。引言解释问题，系统模型给出详细定义，方法部分说明具体求解。

检查办法：给每段写一句“这一段回答什么”。相邻段落回答同一问题时检查重复；两段没有共同对象时检查衔接。

### 6. 文献要保留关键方法，并帮助定位本文

作者反对堆技术名，也反对将文献简化成“联合分配以提高EE”。相关工作需要保留足以区分方法的技术内容，并说明其作用。

- Zhang等：补充Dinkelbach变换处理能效比值目标、结合ADMM求解子信道与功率分配，比仅说提高EE更有信息。
- Yang等：解释公共/私有消息、强用户通过RF向弱用户转发公共消息，再说明优化变量与最低用户速率目标。“协作速率分拆”名称本身不足以完成解释。

文献介绍按本段目的选择性回答：研究优化什么、怎样做、依据什么信息、与本文有何区别。无需每篇机械填满四项，也不用给每篇强加一个缺点。

作者希望删除无关场景标签，但固定接入点、室内环境、已知CSI等条件若决定了方法差别，就应保留。一般异构研究按其真实范围介绍；车用研究应明确突出车用特点。

检查办法：这篇文献为什么放在这里？去掉作者姓名后，能否看出方法区别？这一组研究能否自然引出本文的问题？

### 7. 贡献要说明方法怎样帮助解决问题

作者提供的Paper6导师讨论要求：方法名在后文要有实际内容，贡献落脚点要明确。例如，干扰图分解帮助降低求解规模，就应说清这一作用；仅写“分为若干区域”没有完成贡献说明。

对应Paper3：预测方法怎样帮助判断通信模式和功率是否满足速率要求；平均EE约束怎样控制改善最低EE的代价；连续功率优化怎样协调弱链路改善及对其他链路的干扰影响，都应写清。

检查贡献时可以依次问：针对什么问题？建立什么方法？它改变了怎样的决策能力？后面用什么分析或结果说明作用？这是一套检查顺序，不必机械写成固定句式。

检查办法：摘要、引言贡献、正文方法和实验是否在讲同一件事？删掉技术名后，能否说清这一贡献的价值？

### 8. 准确、自信地说明优势，把限定放对位置

作者反对防御性写作，因为连续使用“只是”“尚不能”“不能保证”会使读者看不到已经完成的工作。

已有结果应直接说明提高什么、相对谁提高、付出什么代价。假设和适用条件放在对应模型、命题或实验设置中；主句应完成对方法或发现的表达。

例如，“在限定预测平均EE下降比例的条件下，提高最低链路EE”已经说明优化对象。“预测”这个必要限定，比紧接一串否定性说明更有效。

如果连续功率优化贡献主要收益，就明确突出；如果额外模式调整在部分状态提供增量，就说明其增量作用。不同模块的角色准确，论文的优点反而更容易看清。

检查办法：读者能否说出本文有什么优点？限定是否具体且必要？是否用泛泛自我否定代替了明确的研究范围？

## 三、典型修改对照

原表述来自本次修改讨论；修改方向综合作者意见与后续稿件，不是外部文献引句。

| 原表述 | 修改方向 | 核心经验 |
|---|---|---|
| V2V通信支持车辆间的信息交换 | 从车用通信在智能交通中的作用切入 | 提供研究意义，避免重复定义 |
| 互补能力能否转化为收益，取决于资源决策对信道状态的判断 | 资源分配的效果受到CSI准确性的直接影响 | 用具体对象直接表达关系 |
| 块初CSI、配置随后保持不变 | 通信周期开始时确定通信模式和发射功率，并在周期内保持不变 | 先解释时间与动作 |
| 改善资源利用效率 | 根据语境写通信性能，或明确写实际评价的EE、速率、QoS | 不增加未定义的性能指标 |
| EE算术平均衡量平均EE | 动机中解释平均EE提高为何不等于弱链路改善，正式定义放建模 | 各部分承担各自的解释任务 |
| 协作速率分拆和联合资源优化 | 解释谁转发什么、优化哪些变量、目标是什么 | 技术内容要可理解 |
| 相对于参考方案的效率损失 | 相对于第一阶段结果的预测平均EE下降比例 | 将代码对象转换成研究含义 |
| 用低分位速率检查最低要求 | 用预测下分位判断是否达到预先设定的最低速率要求 | 区分变化预测量与固定门限 |

## 四、避免把作者要求学偏

| 作者要求 | 正确理解 | 应避免的误学 |
|---|---|---|
| 少写无关背景 | 根据比较目的取舍信息 | 隐去决定适用范围的关键假设 |
| 少用生造术语、表达自然 | 先解释具体对象、动作和作用 | 删除必要技术内容，剩下泛泛总结 |
| 全文统一名称 | 同一概念同名，不同概念区分 | 把目标与指标、门限与预测值混为一谈 |
| 大方表达优势 | 以证据支持的主句说明方法与效果 | 把预测约束写成真实保证，或将局部增量夸成主要收益 |

“朝向”和“视场角”相关但不同，也说明语言压缩需要保留科学含义。它们可以在引言中避免冗长解释，但物理模型仍要准确区分。

## 五、以后怎样实际执行

**第一遍检查论证。** 明确每段的任务，确认背景、困难、已有方法和本文方法能接起来。

**第二遍检查对象。** 将抽象名词和代词对应到变量、信息、动作或指标，查找未定义、随意换名和概念混用。

**第三遍检查研究一致性。** 对照公式和实验，确认动机中的性能确实被评价，贡献中的方法确实被实现，预测约束与真实结果没有混淆。

**第四遍检查表达。** 删除重复定义、空泛过渡语和多余自我限定；保留关键方法细节，拆开难读长句。已经认可且准确的内容保持稳定。

**第五遍说明修改理由。** 重要修改采用“原句—改句—原因”，让作者判断是否忠实于研究意图。一般风格偏好不包装成必须修复的科学错误。

逐段自检：

1. 读者是否知道这一段在讨论什么？
2. 每句话是否提供新的必要信息？
3. 为什么需要这项研究，是否说清？
4. 术语是否有具体对象且前后一致？
5. 文献方法与本文的区别是否明确？
6. 贡献是否说明对问题的实际作用？
7. 性能与结论是否对应公式和证据？
8. 本文优势是否清楚、有分寸地表达出来？

## 七、本次复查补充：从方法名称写到决策作用

以下经验来自2026年11月9日对引言v12、正式算法和已有结果的对应复查。具体改句另列为建议，尚未由作者确认，不代表引言已修改。

### 1. 一个预测结果有多种用途时，要把分工说清

“计算速率分布”只说明得到什么，还没有说明为什么需要它。本文利用周期平均速率预测分布的均值计算链路EE，利用经校准的速率下分位数检查预先设定的最低速率要求。把这两个用途写出来，读者才能看见信道预测怎样同时进入优化目标和约束。

这也提供了一种说明方法特点的办法：先交代新增的决策用途，再判断是否需要技术名称。不能仅凭采用了预测分布，就进一步声称预测比已有方法更准确；精度优势需要对应比较。

### 2. 交代方法区别，要从最接近的工作出发

引言已经介绍信道估计、动态速率预测和机会约束，因此再说“考虑动态信道”不足以让读者看清本文的特点。应具体写出预测覆盖哪个通信时段、在什么通信模式和功率下评价、预测结果怎样用于EE目标和速率检查。

这种正面说明不要求给每篇文献追加缺点。尤其不能把卡尔曼滤波笼统写成“不考虑未来变化”，也不能未经原文核对就声称已有研究“均未考虑干扰”。本文做了什么，与他人完全没有做过，是两种不同的判断。

### 3. 阶段名称和量词也承载科学含义

“每次更新都检查平均EE下降比例约束”容易把两个阶段混在一起。该约束以第一阶段结果为基准，所以应明确它用于第二阶段的候选评价。需要检查的不是句子是否听起来严谨，而是“每次”“所有”“保证”等词是否覆盖了实际适用范围。

用“在公平优化阶段”就能解决的范围问题，不必展开成实现例外说明。后备策略与失败处理放在算法部分集中交代。

### 4. 检查重复时，看有没有增加信息

同一研究目标可以在动机、相关工作和贡献中出现，但三处应分别承担“为什么研究”“相对已有工作增加什么”“具体如何实现”的任务。若1.2导语只是把前文目标再次完整复述，可以压缩导语，保留贡献中的实质内容。

同理，结果段中的三类比较回答不同问题：相对平均EE初始分配说明公平改善的代价；与文献方法适配的对照说明同类方法之间的表现；消融说明某个环节的作用。按需要选择证据，不把它们混成一个笼统的“优于已有方法”，也不为了齐全把所有数字塞进引言。

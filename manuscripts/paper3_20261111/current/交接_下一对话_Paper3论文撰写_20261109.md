## 2. 本文当前真正研究什么

工作题目：**不完美CSI下V2V RF/VLC异构通信的能效公平资源分配**。

主线是：已有信道观测 → 估计和预测通信周期内的信道 → 结合期望信号与同模式干扰计算速率分布 → 检查预测速率要求 → 联合优化通信模式和发射功率，在限制平均EE下降比例的条件下改善最低链路EE。

这篇不是Paper6的恶意车辆类型识别/贝叶斯Stackelberg抗干扰论文，也不是已经训练成功的MASAC/GNN论文。当前10车和50车结果均需按各自数值求解批次描述；100车学习开发不作为本篇已经完成的方法贡献。

### 2.1 优化变量和时间

- 引言统一说**通信模式和发射功率**。按用户本文约定，通信模式含通信车辆选择与RF/VLC方式选择；数学建模仍应把合法连接关系定义清楚，不能真的删除相应变量。
- 不再在引言反复并列“通信配对、模式、功率”来突出配对创新。
- 每个通信周期100 ms，周期开始时作出决策，通信模式和功率在周期内保持不变。当前完整长跑为1000个周期、100秒，块号0–999。
- 不用“块初”“配置执行时长”“条件块”等尚未解释的工程缩写写研究动机。优先说“通信周期开始时”“通信模式和发射功率”。

### 2.2 EE、两阶段优化和速率约束

当前逐链路EE为平均传输速率除以该链路的`Pc+p`。块内先求各链路EE的算术平均和最小值，再对周期汇总。主指标不是总速率除以总功耗，也不以网络EE替代。

第一阶段以**预测平均EE最大化**为目标，求得通信模式和功率的初始分配。第二阶段以**最大化最低链路EE（Max-Min EE）**为目标，同时要求预测平均EE至少保留第一阶段结果的`1−δ`。第一阶段结果是有限搜索输出，不是全局最优上界。

权衡方向：**允许平均EE下降一定比例，以提高最低链路EE。** 不写成“为了提升平均EE付出效率损失”。正文优先用“预测平均EE下降比例”，不要用没有对象的“效率损失”。实际执行可能超过预测预算；这不应被混成约束变量本身。

最低速率要求是**预先设定的固定门限**，当前1 Mbit/s。信道观测、模式和功率变化使预测速率变化，不改变该门限。当前主要预测筛选使用经校准的低分位速率，约束是逐链路的；整周期任一链路违约是评价指标，不等于优化采用了联合机会约束。

当前运行配置还开启了`qos_fallback_mean`后备路径。算法部分须从对应源码准确说明何时使用及如何报告，不能笼统声称所有最终动作均满足校准下分位筛选。既有记录中的均值后备、返回初始动作、未得到可执行动作，是三个不同事件。

### 2.3 CSI术语与刚完成的修改

| 术语 | 准确含义 |
|---|---|
| 信道估计误差 | 对应时刻的信道估计值与真实信道之间的差异 |
| CSI过时 | 获得信息后信道继续变化，旧信息不能完全代表后续状态 |
| 动态信道 | 信道随时间变化这一物理现象，不等于估计误差 |
| 速率预测分布 | 根据已有观测、后续信道变化模型和候选模式/功率得到的预测 |
| 预测下分位速率 | 用来检查固定最低速率要求的预测量，其值随信息和动作变化 |

## 4. 方法、对比与理论的写作位置

### 4.1 外部算法和消融不是一回事

- Aboagye等，TWC 2023：匹配与功率交替优化的适配基线。

### 4.2 理论所服务的问题

用户希望保留“信道信息如何影响服务评价，服务评价如何通过干扰耦合影响可行功率，再影响受平均EE约束的资源选择”这一理论联系。不要将整篇简化成只有Max-Min公平，也不要为了增加定理而重写主算法。

现有理论材料包含：

- CRLB：匹配观测模型下的估计精度下界；不直接等于误差绝对上界、真实95%速率保证或EE损失上界。
- S1：固定通信模式下的最低服务功率/能量数值分析。它与平均EE最大化、最低EE最大化是不同目标，作为机制工具使用。
- S2：原全内点敏感度在早期20配置中0/20适用；很多变量在功率下界。11月v5代码的S2则是固定通信结构下的同模式一阶干扰梯度与功率削减排序，100周期审计有28周期排序为空。这是不同版本和对象。本轮未确认已经实现通用的分段活动集/KKT敏感度。不能仅因旧全内点版本不适用就说“全部S2没有价值”，也不能直接把数值差分写成最优值导数。
- S3：配置成本区间比较；早期校准分位的单调性证明被反例推翻，修订版采用新的保守界。引用旧包时必须核对版本，不恢复已撤销证明。
- Guard：相关候选补救路线未成为当前主方法，不写成已经有效的创新模块，也不将有限搜索失败说成一般数学不可行。

## 5. 作者实际写作习惯：必须从具体例子理解

### 5.1 已确认的偏好

1. **中文先写清楚。** 用户没有要求英文时不自动切英文。文风自然、具体、专业，不靠复杂术语显示学术性。
2. **开头说明应用和问题。** 用户接受“车用通信是智能交通系统的重要组成部分”，拒绝“V2V通信支持车辆间的信息交换”这种重复定义。
3. **每句话有明确对象。** “通信模式和发射功率”优于未定义的“配置”；“通信周期开始时”优于“块初”。不要造“资源评价”“效率收益”“资源利用效率”等没有定义或没有评价依据的名词。
4. **先讲物理原因，再引出方法。** 车辆运动改变信号和干扰，因此估计和预测影响资源分配；平均值提高不意味着弱链路改善，因此需要明确的公平目标。
5. **术语统一，但不混淆不同层次。** Max-Min EE是目标，最低链路EE是指标；通信质量、速率、EE不是同一性能。
6. **贡献和问题一一对应。** 每项贡献应说明解决什么问题、具体方法是什么、后面由哪条分析或实验支撑，不能只排列技术名称。
7. **相关工作按问题分组。** 先说明别人优化什么、采用何种信息/方法，再指出与本文的具体差别。一般RF/VLC研究可不详述无关背景；车用研究应明确强调车用。不能把非车用文献冒充V2V，也不能隐去会使比较失真的关键条件。

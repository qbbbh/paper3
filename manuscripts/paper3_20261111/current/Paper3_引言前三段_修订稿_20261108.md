# Paper3 引言前三段修订稿

> 本轮仅修订v10引言前三段，供逐段审阅与替换。引用沿用原稿[1]—[4]；原稿、相关工作及贡献部分均保留。本文的通信模式选择包含通信车辆的选择及RF/VLC方式选择，行文统一以“通信模式和发射功率”概括优化变量。

车用通信是智能交通系统的重要组成部分，车辆对车辆（vehicle-to-vehicle，V2V）通信在提高交通安全与通行效率方面发挥着重要作用[1]。射频（radio frequency，RF）通信具有较广的覆盖范围，但共享频谱的链路之间存在同频干扰。可见光通信（visible light communication，VLC）利用车灯传输数据，具有较强的方向性，有利于空间复用[2]，但其通信质量受到车辆相对位置、收发角度和遮挡的影响[3]。通过联合优化车辆间的通信模式和发射功率，RF/VLC异构资源分配能够发挥两种通信方式的互补优势，改善车用通信系统的通信性能。

资源分配的效果受到信道状态信息（channel state information，CSI）准确性的直接影响。车辆运动会改变接收信号强度以及其他车辆产生的干扰；车用VLC实测也表明，转弯和车辆垂直运动会引起接收功率变化，从而影响车辆间的通信效果[4]。在本文考虑的周期性资源分配中，系统在每个通信周期开始时根据已有CSI确定通信模式和发射功率，并在该周期内保持不变。信道估计偏差不仅影响本链路的速率判断，还会通过通信模式和发射功率的选择影响其他链路的服务质量（quality of service，QoS）。因此，资源分配需要考虑估计误差以及通信周期内的信道变化，联合预测各链路的传输速率及其相互干扰。

除了满足通信质量要求，RF/VLC异构资源分配还需兼顾能效（energy efficiency，EE）与链路间的公平性。由于高EE链路能够抬高平均值，平均EE的提高并不意味着低EE链路也得到改善。最低速率约束也不足以保障能效公平，因为不同链路达到相同速率所需的功耗可能不同。另一方面，直接最大化最低EE又可能牺牲较多平均EE。因此，本文研究不完美CSI下通信模式与发射功率的联合优化，在满足预测速率约束的同时，以给定的预测平均EE损失预算提高最低链路EE。

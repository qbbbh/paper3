# 作者引言写法总结（对齐 IEEE TVT / IoT-J 气质）

依据：第6篇中文定稿引言、第5篇英文改写稿、开题报告引言思路。  
用途：重写 Paper3 引言时遵循，**不要**写成“问题堆砌 + 贡献清单口号”。

---

## 1. 你真正想要的结构（TVT/IoT-J 常见骨架）

| 块 | 作用 | 你第6篇的对应 |
|---|---|---|
| 开篇动机 | 场景→技术互补→自然落到**本文决策变量** | §1 前两段 |
| 问题收窄 | 用 2–3 句钉死**本文独特难点**（不是百科） | §1 第3段 + “基于上述背景…” |
| Related Work | **分主题小节**，每节：代表工作→共同局限→与本文差别 | §1.1 A/B/C |
| Gap 汇聚 | 一小节或段末显式写出空白 | 各小节末 + 贡献前过渡 |
| Contributions | 与方法一一对应，**可被实验核验** | §1.2 第一/二/三 |
| 组织句 | 一句话指路 | 段末 |

第5篇英文改写同样是：动机 → Related Work 分小节 → Proposed Framework and Contributions。这就是 TVT 气质，不是 MDPI 式“背景很长、贡献很虚”。

## 2. 文风要点（从你已发表/定稿稿抽出）

1. **先定义对象，再评价文献**  
   例：先写“恶意车辆可观察策略后调整干扰”，再进 Stackelberg 文献；不要先堆博弈名词。

2. **文献段必须有“差别句”**  
   每引一组工作，至少一句：它们解决了什么、**未覆盖本文哪一约束**（信息不完全对象不同、静态室内 vs 车载、只拓扑不功率、平均 EE 无瓶颈约束等）。

3. **贡献用“提出/建立/给出”+ 可检验内容**  
   避免“首次全面解决”“显著优于一切”。第6篇贡献都对应后文一节方法。

4. **术语中英并列一次即可**  
   V2V、RF、VLC、EE、CSI 等在首次出现括注，后文统一。

5. **不做未证实的因果口号**  
   第5篇审稿改写明确反对“以前都没有 GNN–MARL”；Paper3 也不要写“配置不匹配往往是主因”——应用实验可支持的机制表述。

6. **Related Work 按问题切，不按年份流水账**  
   开题思路：信道/架构 → 资源分配方法代际 →（大论文才有）安全；Paper3 应切成：异构 VLC/RF 分配、不完美/过时 CSI、能效与公平/瓶颈 EE。

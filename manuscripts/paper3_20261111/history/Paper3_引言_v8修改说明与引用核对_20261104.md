# v8修改说明与引用核对（2026-11-04）

## 本轮修改的重点

v7存在的问题不只是冗长。它把内部审查中用于限制主张的提醒直接放进了论文叙述，削弱了研究动机和方法介绍。v8保留事实边界，但按“为什么研究—已有工作做到哪里—本文如何推进”组织文字。

本文值得正面突出的是：**把不完美CSI下的块级服务评价、可调节的平均EE损失预算和最弱通信对改善联系起来，并用连续功率细化实现这一取舍。** 这比强调“没有采用什么”“不能保证什么”更准确，也更利于读者理解工作价值。

| 修改点 | v7的具体问题 | v8处理 |
|---|---|---|
| 背景 | “可借助车载照明提供与RF不重叠的频谱”表达生硬 | 改为“利用车灯传输数据，可补充RF通信资源”，再说明方向性和空间复用 |
| 光学限制 | “视距、朝向与视场角限制”罗列但不解释关系 | 写为“车辆相对位置、收发角度和遮挡会改变光链路的增益与可用性”；不将朝向与FOV视为同义词 |
| 研究动机 | “优化目标同样需要收窄”是内部讨论语气 | 解释平均EE、最低速率和最低EE解决的是不同问题，再引出损失预算 |
| 方法价值 | “不改进估计器”“不以学习型策略为贡献”等反复退让 | 直接介绍从条件预测到服务分位、从预算到公平细化的作用 |
| 贡献 | “形式上包含”“实证主杠杆”“稀有配置纠正仅作旁证”削弱正文 | 使用“平均能效损失预算下的最弱通信对优化”“预算约束下的连续功率细化”等可解释表述 |
| 结果 | 把失败记录、回退及一串否定性保证挤进贡献 | 保留主要结果及连续功率机制，详细审计和局限留在方法/实验相应位置 |
| 指标 | 网络EE、平均EE和平均逐链路EE混用风险 | 开篇明确平均逐链路EE是各通信对EE的算术平均；已有网络EE工作保留其原指标名称 |

## 文献定位的实质修正

1. **Papanikolaou 2020已经考虑公平性与不完美CSI。** v8据此描述，不以“前人使用理想CSI且不考虑公平”为研究缺口。
2. **Ding 2020直接研究Max-Min EE。** 本次加入，明确最低EE优化已有基础；本文差异在动态V2V的条件服务评价和相对平均EE参考的预算。
3. **Yang 2025研究聚合VLC/RF的Max-Min速率。** 本次加入，用于区分速率公平与能效公平，避免把它们当成同一个目标。
4. **Al-Hammadi 2021主要推导和速率与EE性能。** 改正v7将其笼统归为接入/功率优化设计的表述。
5. **Wu 2018的ANRO处理功耗—时延与队列。** 按其实际目标介绍，本文不因此增加队列或改成该目标。
6. **LED—摄像机CRLB不再出现在引言中。** 文献和笔记仍保留在扩展阅读。它与本文PD观测模型不对应，用于引言核心论证会分散重点；正文估计章节可采用匹配模型下的估计文献。

v8共20篇正文参考，原v7的23篇文件保持原样。本文引用数量不是优化目标；取舍依据是每篇是否支持当前段落的明确论点。Shapley-DQN和GNN-D3QN等课题组成果保留在大论文学习章节文献清单，不在Paper3引言中额外展开无关的算法路线。

## 建议保持稳定的内容

保留平均逐链路EE定义、预测预算、块内配置不变、RF/VLC同模式干扰以及连续功率细化。正文最需要读者记住的是“在服务要求和平均效率代价之间，有组织地改善最弱通信对”，而不是候选列表、失败日志或内部模块名。后者在方法与实验中说明即可。

语言层面借鉴了作者Paper5、Paper6引言的问题驱动组织方式，以及本轮TVT/IoTJ原文的相关工作分组；没有改动两篇既有稿件。本轮不涉及模型、算法、参数或仿真修改。

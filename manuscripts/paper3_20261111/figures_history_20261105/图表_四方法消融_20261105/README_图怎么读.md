## 已得到的具体结论

### 1. 连续细化的作用不仅体现在一个平均数

10车两种信道实现中，相对平均EE参考：

| 最低EE收益门槛 | 完整方法A / B | 无连续细化A / B |
|---|---:|---:|
| 有正增益 | 81.4% / 83.4% | 35.9% / 36.7% |
| 至少增加1 Mbit/J | 62.1% / 61.4% | 30.8% / 32.3% |
| 至少增加10 Mbit/J | 53.5% / 53.9% | 22.1% / 26.0% |
| 至少增加50 Mbit/J | 24.7% / 31.0% | 3.2% / 3.7% |

因此，“无连续细化的配对增益中位数为零”表示多数块没有变化，不表示所有块没有收益。完整方法既扩大了受益范围，也增加了达到较大收益的块数。

这些门槛只是展示效果量的刻度，不是新增QoS、算法接受条件或事后筛选规则。图中显示了完整的0、1、5、10、20、50 Mbit/J序列。

### 2. 最弱的一档确实受益，但不是所有状态收益都一样

按参考方案的块内最低EE，从低到高分为四档，每档约249–250块：

| 分档 | 完整方法A / B：最低EE配对增益中位数（Mbit/J） | 无连续细化A / B |
|---|---:|---:|
| Q1：参考最弱的四分之一 | 11.34 / 13.51 | 0 / 0 |
| Q2 | 23.89 / 24.50 | 0 / 0 |
| Q3 | 39.41 / 49.84 | 0 / 0 |
| Q4：参考最强的四分之一 | 0.018 / 0.033 | 0 / 0 |

这说明连续细化并非只改善少数原本强的块；最弱一档也获得了明显的典型收益。绝对增益在中间两档更大，最强一档的典型增益则很小。该分组是状态条件描述，不等同于因果识别。

### 3. 收益伴随真实执行差异

完整方法A/B的平均EE损失中位数为6.69%/7.03%。同时满足“最低EE增加、实际平均EE损失不超过10%”的块为61.4%/59.1%；无连续细化为31.9%/33.0%。

完整方法的最低EE实际下降块占17.5%/16.1%，实际损失超过10%的块占20.8%/24.6%。这些块已保留在图2中。算法按预测量筛选，图展示同一真实信道下的执行收益和代价。

### 4. 同配置细化适合小表或简短机制说明

| 同批次比较 | 最低EE相同 | 完整方法更高 / 更低 | 完整−同配置最低EE均值（Mbit/J） |
|---|---:|---:|---:|
| 10车短窗口A | 70/100 | 9/21 | +0.127 |
| 50车A | 94/100 | 3/3 | +0.272 |
| 50车B | 95/100 | 3/2 | −0.002 |

“相同”判据为绝对差不超过1e−9 Mbit/J；它只是数值一致性判据。少量差异中的正负号也不直接代表有实质意义，具体大小见逐块CSV及图3。

本批数据支持将连续功率细化作为主要消融，把额外配置搜索的增益放在一张小表中说明。完整方法本身仍保留配置选择，不据此修改算法。

## 四种方法为什么分组画

| 数据组 | 参考 | 完整 | 无连续细化 | 同配置细化 |
|---|---|---|---|---|
| 10车长窗口A/B：源码3cab6609、预测基础种子2026102501 | 有 | 有 | 有 | 无 |
| 10车短窗口A：源码d2f014ff、预测基础种子2026102501 | 有 | 有 | 无 | 有 |
| 50车短窗口A/B：源码d2f014ff | 有 | 有 | 无 | 有 |

10车长窗口每次计划999块，共99.9 s；B有1个配对失败块，图用998块。短窗口均为100块、10 s。同一规模的A/B是两个信道随机实现，不是两个独立交通场景。

现有归档没有一组完整、同版本同窗口的四方法数据。本轮把四种方法放在对应的有效比较中展示。10车长窗口的完整/无细化参考动作、预测种子、实际EE已逐块核对一致；短窗口的源码版本和评价窗口不同，同块参考动作也未逐位一致，因此单独成图。各组预测基础种子均为2026102501；逐块记录的种子等于基础种子加块编号。

## 数据与复现

- `source_blocks.csv`：逐块源数据，包括失败状态、版本和随机种子。
- `method_summary.csv`：每方法的中位数、正/零/负收益、实际预算与QoS结果。
- `quartile_response.csv`：参考强弱分档的收益。
- `gain_threshold_coverage.csv`：图4各格的计数及分母。
- `fixed_configuration_block_differences.csv`：图3每个点。
- `provenance.json`：7个来源批次、结果哈希、完整冻结配置。
- `render_audit.json`：绘图后端与数据范围检查。

执行 `extract_source_data.py` 后执行 `make_figures.py` 可以从归档重新出图；单独执行后者可用本目录CSV重画。所有单链路EE均按对应批次的 `actual_rate_bps/(power_w+Pc_mode)` 独立复算，最大相对误差小于1e−12。未使用总速率/总功耗作为主指标。

统计以块为单位，先算块内各链路EE的算术平均及最小值；本轮不加独立样本置信区间、不平滑、不裁去异常点。分布中位数之差与逐块差值的中位数是不同统计量，正文使用时对应标明。

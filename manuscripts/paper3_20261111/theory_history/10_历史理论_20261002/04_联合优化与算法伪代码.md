# 联合优化与可实现算法伪代码

本文件对应当前研究原型 `prototype/problem.py`、`prototype/feasibility.py`、`prototype/solvers.py` 和两项文献适配入口。它描述实际求解问题与停止规则，不预设实验优劣，不把有限迭代输出称为已认证驻点或全局最优。物理定义、估计界和迁移命题分别见文件01、03；文献适配逐式出处见 `literature_baselines/SOURCE_MAPPING.md`。

## 1. 决策时刻的信息与输入

业务为 K 条固定发送—接收配对，所有业务均需服务。数据阶段每条链路恰选一个模式，m_i∈{0,1}分别表示RF、VLC；连续发射电功率p_i以W表示。原型采用同模式干扰，跨RF/VLC不互相干扰。接收者i的数组行、发射者j的数组列不能交换：

\[
\mu^r_{ij}(t),\quad V^r_{ij}(t),\qquad
\mathrm{shape}=(2,K,K).
\]

\(\mu\)为给定当前可用观测的条件均值近似，\(V\)为对应条件残差方差近似。归一化信道H的参考功率为\(P_0>0\)。实际存入分配器的协方差来自粒子后验矩；CRLB仅作独立估计性能基准，不能自动替换这些方差。一个接收者的光/RF、有用/干扰链路使用共同几何粒子，所以生成模型保留相关几何；当前二阶矩SINR由于独立零均值数据假设只用所需边际二阶矩，未实现另一套相关误差鲁棒SDP。

**当前观测时序。** `ReceiverParticleFilter.observe(y,energy)`在t=0处理独立导频块，观测充分统计量为\(y=\sqrt E H+n\)。`predict(t)`随后将同一个初始位置、速度和朝向后验通过几何传播到年龄t，不接收未来真值或未来观测。这里t是同一轮观测的预测年龄，不是每调用一次优化器就重新发一组导频。它是固定未知运动状态的数值重要性采样预测器，不是已经实现持续重采样、逐时隙新观测的完整粒子滤波器。

`predict(t)`输出均值、方差、可见概率、有效样本数ESS及诊断。RF设为可用；VLC按预测可见概率是否达到配置门槛确定候选可用性。这是模型内候选策略，**不是已经校准的条件可靠性保证**；输出明确标为`posterior_is_approximate=True`、`coverage_validated=False`。低ESS需在实验中报告，不能因优化器找到可行功率就证明后验可靠。FOV截断由逐粒子几何处理，不在跨边界位置强行使用光滑线性化。

`make_problem(mean,variance,available,cfg)`将这些信息和固定配置转换成统一 `Problem`。优化接口不接收独立评价所用真实状态；任何未来真值只用于冻结决策后的结果评价。

## 2. 当前实际优化问题、单位与整帧成本

### 2.1 固定模式下的代理速率

选定模式后，定义

\[
a_i=\frac{|\mu^{m_i}_{ii}|^2}{P_0},\qquad
s_i=\frac{V^{m_i}_{ii}}{P_0},\qquad
b_{ij}=\mathbf1_{\{m_i=m_j\}}
\frac{|\mu^{m_i}_{ij}|^2+V^{m_i}_{ij}}{P_0}\quad(j\ne i).
\]

a、s、b均有1/W量纲；p以W计。令\(B_{ii}=s_i,B_{ij}=b_{ij}\)，则

\[
D_i(p)=n_i+(Bp)_i,\qquad
\gamma_i(p)=\frac{a_ip_i}{D_i(p)},\qquad
R_i(p)=w_i\log_2(1+\gamma_i(p)).
\]

\(n_i>0\)是规范化接收噪声。\(w_i=\tau B_{m_i}\kappa_{m_i}\)，RF \(\kappa_R=1\)，本轮VLC \(\kappa_V=1/2\)，\(\tau=1-\alpha_{\rm ctrl}\)。配置的带宽单位为MHz，所以代码速率单位是Mbit/s，\(\mathrm{EE}=\sum R_i/C\)单位是Mbit/J。

VLC式子是统一工程速率代理，不是已经证明适用于当前非负输入/FOV混合后验的IM/DD容量下界。即使QoS代理不可行，也不能推断真实容量或任何实际编码必然失败。本轮没有做实际译码器或误包率实现。处理功耗与发射功率接口参考Chen/Aboagye，参考SNR仍是研究设定，因此数值EE不是设备实测结果。

### 2.2 整帧平均功耗

当前代码将速率与数据阶段功率都乘数据占比，避免仅扣导频时间却仍用整帧数据功耗：

\[
C(m,p)=C_{\rm ctrl}
+\tau\sum_{i=1}^K
\left(P_{\rm proc}^{m_i}+\zeta_{m_i}p_i\right)>0.
\]

\(\zeta_r\)取配置中的功率转换/成本系数；若只是偏好权重，结果应称加权效率，不能称真实bit/J。数据阶段只计所选模式的处理功耗。代码固定项为

\[
C_{\rm ctrl}=P_{\rm common}
+K\left[
\alpha_{\rm ctrl}\sum_{r\in\{R,V\}}P_{\rm proc}^{r}
+\frac{L_pT_p}{T_{\rm slot}}
\sum_{r\in\{R,V\}}P_{\rm pilot}^{r}
\right].
\]

这里导频长度、导频功率和控制占比均固定，不是优化变量。两模式观测对应控制阶段的共同开销，所有方法都承担相同口径。**该扣减是保守的共同平均开销约定，不意味着年龄t的每个决策时刻都生成了新导频。** 当前同一t=0观测之后的多次预测应理解为观察周期内不同年龄/快照的分配评价；升级为长期重复帧实验时，需给出实际训练周期并按周期摊销能量，不能把这些快照的能耗简单加总。

### 2.3 联合问题

\[
\begin{aligned}
\max_{m,p}\quad&
\frac{\sum_iR_i(m,p;\mathcal I_0,t)}{C(m,p)},\\
\mathrm{s.t.}\quad&
m_i\in\{0,1\},\quad \mathrm{available}[m_i,i]=\mathrm{True},\\
&0\le p_i\le\bar p_i^{m_i},\quad
R_i(m,p)\ge R_i^{\min}>0,\quad i=1,\dots,K.
\end{aligned}
\]

当前没有拓扑/路由、子信道、导频、波束、切换代价或跨时隙能量约束。因此每个年龄t更新一次信息并求解一次静态联合问题；不称新MPC或跨时域联合控制。QoS不允许通过删掉难服务业务规避；不可行需返回明确状态。

## 3. 精确设计可行性筛查与初始化

### 3.1 固定模式

因\(w_i>0\)，令\(\theta_i=2^{R_i^{\min}/w_i}-1>0\)。当前模型的业务约束**恰好**等价于线性不等式

\[
a_ip_i\ge\theta_i\big(n_i+s_ip_i+\sum_{j\ne i}b_{ij}p_j\big).
\]

首先检查\(d_i=a_i-\theta_i s_i>0\)。若有\(d_i\le0\)，由于噪声严格正，该固定模式无有限QoS可行功率。否则令

\[
F_{ij}=\begin{cases}\theta_i b_{ij}/d_i,&j\ne i,\\0,&j=i,\end{cases}
\qquad u_i=\theta_i n_i/d_i.
\]

`minimum_power(problem,modes)`依次检查候选可用性、正精度裕量、\(\rho(F)<1\)，再解

\[
(I-F)p_{\min}=u.
\]

实现用线性方程求解器，不直接求逆。最后检查\(p_{\min}\le\bar p\)，返回最小功率、谱半径、方程残差和帽余量。给定非负系数、固定误差统计和严格正基础需求，这是**当前设计代理**的充要可行性判据；不保证真实解码。接近\(\rho=1\)时需关注数值条件，有限精度的阈值比较不等价精确算术证书。

### 3.2 单条模式切换

`switch_certificate(problem,old_modes,moved)`先将moved链路k切到另一模式，再分别检查迁出后剩余网络与迁入前目的网络。目的网络旧业务的矩阵记为M，最小功率\(v=M^{-1}q\)；新增业务对旧业务的需求耦合为g，旧业务对新业务的耦合为b。实现通过线性方程得到\(w=M^{-1}g\)。

\[
\delta=d_k-b^\top w,\qquad
N=q_k+b^\top v,\qquad
p_k^{\min}=N/\delta,\qquad
p_D^{\min}=v+wp_k^{\min}.
\]

帽给出迁入业务允许功率

\[
U=\min\left\{\bar p_k,\ \min_{j:w_j>0}
\frac{\bar p_j-v_j}{w_j}\right\}.
\]

目的网络为空时，反馈为0、U只含新增业务自己的帽。迁入要求\(\delta>0,U>0,N/\delta\le U\)，并要求迁出剩余网络可行。由此输出允许自残差系数预算

\[
s_k\le s_k^{\rm crit}
=\frac{a_k-b^\top w-N/U}{\theta_k}.
\]

代码字段`critical_c_per_w`对应这里的\(s_k=V_{kk}/P_0\)门槛，单位为1/W；`critical_variance=P0*critical_c_per_w`已经转换成原输入数组V的方差门槛。当前\(P_0=1\)W时二者数值一致，概念仍应分开。完整证明和反例见文件03。

筛查仅决定是否值得求连续功率、以及提供解释，不直接决定EE更优。**切换可行不等于切换改善EE**；原模式不可行也不等于另一模式必然可行。代码进一步用原问题约束复验迁移最小功率，并记录与完整固定模式判据的核对结果。

### 3.3 初始模式与失败边界

默认先尝试RF-only、VLC-only和名义贪心三种模式，若提供`initial`则优先加入。贪心在各模式半功率帽处按无交叉干扰的单链路代理速率选模式，仍保留自身误差；其输出只是初始化候选，不自动可行。

若这些种子均失败，尝试每个种子的所有单比特邻居，并对每个候选检查全网可行性及重新优化。此恢复程序没有搜索全部\(2^K\)模式：未找到可行解通常应返回`feasible_solution_not_found`，不能宣布全网不可行。只有全部模式均检查完、且每个模式均被设计可行性判据拒绝，才使用`certified_design_infeasible`。

## 4. 主算法：固定模式的SCA外层与固定代理的Dinkelbach内层

### 4.1 凹速率下界

固定m时，\(D_i(p)\)仿射，\(A_i(p)=D_i(p)+a_ip_i\)仿射且正：

\[
R_i=\frac{w_i}{\ln2}\big[\ln A_i(p)-\ln D_i(p)\big].
\]

在当前可行点\(p^{(k)}\)、\(D_i^{(k)}=D_i(p^{(k)})\)，对凹函数\(\ln D_i\)使用全局切线上界，得到

\[
L_i(p;p^{(k)})=\frac{w_i}{\ln2}
\left[\ln A_i(p)-\ln D_i^{(k)}
-\frac{D_i(p)-D_i^{(k)}}{D_i^{(k)}}\right]\le R_i(p).
\]

L对p凹，锚点同值同梯度。自身误差项随数据功率增长但系数s固定，因此D仍仿射；如果改成由数据功率决定的训练误差、功率相关噪声或其他非线性，必须重推，不能保留该证明。

SCA主EE代码直接保留**原模型等价的线性QoS约束**\(a_ip_i\ge\theta_iD_i(p)\)，而不是额外用\(L_i\ge R_i^{\min}\)限制EE问题。因此业务可行域没有因SCA速率下界再收缩；下界用于目标。在PF和QT方法中还有其各自代理域/QoS约束，见第6节。

### 4.2 固定代理下的分式求解

分母C严格正且固定模式下仿射。**一轮SCA的全部内层迭代始终固定同一个锚点**，求

\[
\max_{p\in\mathcal P(m)}
\frac{\sum_i L_i(p;p^{(k)})}{C(m,p)}.
\]

Dinkelbach内层第l步解凸问题（最大化凹函数）

\[
p^{(l+1)}\in\arg\max_{p\in\mathcal P(m)}
\left[\sum_iL_i(p;p^{(k)})-\lambda_l C(m,p)\right],
\]

并用**同一代理分子**更新

\[
\lambda_{l+1}=
\frac{\sum_iL_i(p^{(l+1)};p^{(k)})}{C(m,p^{(l+1)})}.
\]

当前代码从\(\lambda_0=\mathrm{EE}(p^{(k)})\)开始；代理在锚点同值，当前点满足差值为0。求解记录
\(r_l=\sum_iL_i-\lambda_lC\)，其绝对值小于容差时可停止本轮内层。代码对λ加非负保护。**不能在同一内层一边更新锚点一边声称仍在求同一个Dinkelbach问题；也不能把更新分子换成真实速率而不重审证明。**

内层候选重新计算真实本轮代理速率和全部原约束。若QoS/帽/可用性失败，则拒绝；若真实EE显著下降，则保留旧可行点并记录数值停滞。外层接受后才更新锚点。变量内部用\(p_i=\bar p_i z_i,\ 0\le z_i\le1\)改善数值尺度，这只是等价缩放，不是新增优化变量维度或重新定义电功率。

### 4.3 理论能说到哪里

在每个固定代理子问题被精确求解、分母正、可行域紧、代理同值同梯度且满足相应约束正则性等条件下，可以讨论MM/SCA单调性和固定模式极限点的驻点性质。它们不是“算法用了SCA所以自动收敛”的事实。

当前原型有有限外/内迭代数、软时间预算、数值容差和求解器可能返回`optimal_inaccurate`。它只把返回点按原式复验，并保存接受过程。实际结果明确设置`stationarity_certified=False`。保存的`fp_residual`仅是**当前固定代理分式差值**，不是KKT残差，更不是混合整数全局间隙。小目标变化也可能是迭代上限、数值停滞或局部平坦造成。

## 5. 模式邻域与完整伪代码

### 5.1 对外接口

| 函数 | 输入 | 主要输出/用途 |
|---|---|---|
| `make_problem(mean,variance,available,cfg)` | 当前可用预测信息和固定配置 | 统一 `Problem`，不传未来真值 |
| `Problem.coefficients(modes)` | 长度K模式向量 | a,s、同模式系数矩阵、噪声、率系数、SINR门槛、帽 |
| `Problem.evaluate(modes,power)` | 当前模式与连续功率 | rates、SINR、cost、EE、sumrate、PF、QoS残差、帽违反 |
| `minimum_power(problem,modes)` | 固定模式 | 可行性原因、p_min、ρ、帽余量、方程残差 |
| `switch_certificate(problem,old_modes,moved)` | 当前模式与待迁移业务下标 | 迁移可行性、δ、U、误差预算、候选最小功率 |
| `solve_power(...,objective="ee",method="sca")` | 固定模式、选项、可选可行起点/截止时间 | 连续功率、原式评价、历史、诊断和状态 |
| `solve_joint(...,objective,power_method,...)` | 统一问题、模式搜索/枚举/固定模式选项 | 最佳已找到可行分配、尝试模式、时间与证书标签 |

`solve_joint`对每个已访问模式缓存该次连续优化结果。同一模式重复出现时复用缓存，不重复获得更多求解时间；这样有利于统一开销，但也意味着某次有限迭代的较差连续解可能限制后续邻域选择。当前非枚举主法每个模式默认从最小可行功率开始。

### 5.2 整体流程

以下“真实目标”指用本轮原始设计速率式重算的EE/PF，**不是实测吞吐**。

~~~text
INPUT:
  已知发送车辆轨迹/初始接收状态先验，固定业务配对
  t=0导频观测y、固定导频能量E
  功率帽、带宽、正QoS、模式处理功耗、平均控制开销
  options以及待评价的预测年龄t
OUTPUT:
  模式m、连续功率p、原式代理指标、失败原因、运行时间、求解诊断

1. 在t=0用y更新接收状态粒子后验。
2. 在年龄t以相同后验预测几何、RF/VLC均值和实际误差二阶矩；
   获取预测FOV可用性与ESS；不读未来真值。
3. make_problem；启动整个solve_joint的截止时间；清空模式缓存。
4. 对initial(若有)、RF-only、VLC-only、greedy种子：
     a. 如已缓存，复用；
     b. 用minimum_power进行设计可行性筛查；
     c. 可行则调用固定模式全网功率求解器；
     d. 输出必须通过原式复验；按指定目标选当前最佳可行点。
5. 若没有可行点：
     对每个种子的每一条链路生成单比特邻居；
     用switch_certificate检查迁出、迁入与所有功率帽；
     可行则重新优化全网功率，复验并更新最佳点。
6. 若仍无可行点：
     若全部2^K模式均已按设计判据拒绝，返回certified_design_infeasible；
     否则返回feasible_solution_not_found；
     保留已尝试模式、失败原因和时间；结束。
7. 最多mode_sweeps轮：
     improved=False
     对i=1,...,K：
        用当前最佳m生成仅翻转m_i的邻居m'
        如缓存命中，读取已有结果；
        否则Schur筛查，随后调用所选连续求解器重优化全网p'
        若原约束可行，且真实目标值 > 当前最佳 + acceptance_tol：
           接受(m',p')，improved=True
        达到截止时间则退出
     若没有改善或达到时间预算则退出
8. 返回最佳已找到可行点和所有记录，global_optimality_certified=False。
9. 冻结上述决策，再用独立真实信道评价业务SINR/速率代理。
   不将评价真值回灌预测分配。
~~~

该流程是依顺序的单比特模式邻域，接受一次切换后，后续候选基于更新的当前模式。它不是同时翻转多个模式，也不是每轮全局选择最佳模式组合。模式接受要求严格超过容差，固定连续子问题的外层只拒绝显著下降；两种接受规则服务不同层次。

### 5.3 固定模式连续求解流程

~~~text
POWER(problem,m,objective,method,deadline,start=None):
  cert = minimum_power(problem,m)
  若cert拒绝：返回design_infeasible及原因
  p = cert.p_min
  若start提供且原式可行：p = start

  建立功率缩放z和当前模式固定的原QoS线性约束
  预建CVXPY问题，通过参数更新SCA或QT代理

  for outer < sca_max:
     prev = 原式evaluate(m,p)
     固定当前锚点，更新SCA切线系数或QT辅助变量
     lambda = prev.EE

     for inner < fp_max（EE）或1次（PF/sumrate）:
        在剩余时间内调用CLARABEL
        若无有效数值候选：退出内层，保留已知可行点
        将z换回瓦特功率；轻微截断到[0,cap]后重新检查原约束
        若原式复验失败：拒绝候选并记录
        用当前固定代理计算low与fp_residual
        记为本轮proposal
        非EE，或|fp_residual|满足内层容差：退出内层
        lambda = sum(low)/cost；不更新锚点

     若没有proposal：记录solver_or_time_limit_with_incumbent，返回旧点
     若proposal真实目标显著低于prev：记录numerical_stall_feasible，返回旧点
     接受proposal；保存功率、QoS余量、真实目标、代理和fp_residual
     若真实目标变化满足相对停止条件：结束
     若到截止时间：保留当前可行点结束

  返回原式evaluate(m,p)、状态、history、diagnostics
  stationarity_certified=False
~~~

对固定模式，当前代码将每个代理子问题做凸求解，但保留的是经原式核验的可行点。求解器异常或时间上限不把已有可行点丢掉，也不把“求解器没收敛”改写成“该模式设计不可行”。

## 6. 两个文献适配与主算法的具体差异

| 方法 | 连续功率目标与代理 | 模式接受指标 | 保留/改动边界 |
|---|---|---|---|
| 主算法SCA + Dinkelbach | 固定切线速率下界的系统EE；内层固定代理分式迭代 | 原式EE | 本轮组合求解器；无全局或已认证驻点结论 |
| Aboagye 2023适配 | SINR二次变换；先求局部和速率参考，再ε门槛下最小功耗，按原式EE挑选 | 原式EE | 保留相关RF/VLC应用论文的QT/ε功率流程；取消AP/子信道/聚合、统一误差模型 |
| Papanikolaou 2020适配 | 固定时频维度的误差感知\(\sum_i\log R_i\)；用SCA正速率下界 | 原式PF | 保留原比例公平目标；本轮同模式干扰使原论文凸化证明不可直接迁移 |

### 6.1 Aboagye QT–ε适配

固定模式、当前p下更新

\[
y_i=\frac{\sqrt{a_ip_i}}{D_i(p)},\qquad
\phi_i(p;y)=2y_i\sqrt{a_ip_i}-y_i^2D_i(p).
\]

固定y后\(\phi_i\)凹，且\(\phi_i\le\gamma_i\)，锚点同值；\(\phi_i\ge\theta_i\)确保正log域与真实QoS。先以QT迭代最大化\(\sum_iw_i\log_2(1+\phi_i)\)，得到局部可行和速率参考\(R_{\rm ref}\)，不是有证书的全局最大率。

以最小可行功率的总率\(R_{\rm floor}\)为下端，扫描

\[
\epsilon_\lambda=R_{\rm floor}
+\lambda\max(0,R_{\rm ref}-R_{\rm floor}),
\]

每个ε下交替更新y并最小化C，使代理总率≥ε且全部QoS成立。每次候选按原速率复验ε/QoS/帽，只接受功耗不显著上升的点。默认扫描λ={0.25,0.5,0.75,1}；配置可改为10点。最小可行功率种子和和速率参考也进入EE候选，不故意遗漏低功率可行点。

函数保存`epsilon_scan`与`rate_reference`，但4点或10点扫描都不是精确Pareto边界。对原文应用流程和所有改动的详细出处见来源映射；不称原方法完整复现。

### 6.2 Papanikolaou误差感知PF适配

在与主法相同的信息、模式可用性、QoS、帽和成本评价下，连续子问题解

\[
\max_p\sum_i\log L_i(p;p^{(k)}),
\qquad L_i(p;p^{(k)})\ge R_i^{\min}>0.
\]

正凹下界经递增凹log复合仍为凹目标，按真实PF接受并用于模式比较。速率数值采用Mbit/s，等价于先除固定单位\(R_0=1\)Mbit/s再取log；该常量不改变最优解。它回答公平分配与EE的目标取舍。不能因为其EE较低就称原论文算法较差；应同时看服务可行性、总率和公平性。该方法的QoS代理内近似与主EE直接线性QoS有所不同，已保留实现透明性。

## 7. 小规模枚举参考及其证书边界

`solve_joint(enumerate_all=True)`逐一检查\(2^K\)个模式，但受`max_enumeration_k`和共同时间预算限制。对可行模式，SCA求解先用最小功率初点，再尝试通过线性QoS可行域最大化\(\sum_i p_i/\bar p_i\)得到的高功率可行初点。第二起点也要通过原式复验，最后保留目标较好的局部结果。不能直接用所有发射者同时满帽作可行起点，因为同模式干扰可能破坏QoS。

该参考应称**枚举模式 + 至多两个连续局部初点**。即使所有模式检查完，连续子问题仍没有全局上下界，所以不是全局最优参考。预算耗尽时可能只覆盖部分模式或第二起点未执行，必须同时报告：

- `search="enumerated_local"`：请求的搜索类型；
- `enumeration_requested`：是否主动请求全模式枚举；
- `mode_candidates`及`attempted`：实际检查数量与模式明细；
- `enumeration_complete`：是否实际覆盖所有模式；请求枚举不意味着完整；
- `global_optimality_certified=False`；
- 连续层`stationarity_certified=False`及各自停止诊断。

非枚举主搜索也可能碰巧访问所有模式；只有当记录确实全覆盖且每个模式都被可行性判据拒绝时，才可报告当前设计问题不可行。某个可行模式连续优化超时只说明该局部优化未完成，不能归入“已证明不可行”。

## 8. 容差、时间预算与状态解释

算法默认参数来自`solvers.DEFAULTS`；实验配置可覆盖，最终运行应保存生效值。

| 参数 | 默认值 | 作用及限制 |
|---|---:|---|
| sca_max | 10 | 固定模式外层上限，不等于收敛证书 |
| fp_max | 10 | 单个固定代理Dinkelbach内层上限 |
| mode_sweeps | 3 | 最多三轮单比特邻域；未穷尽所有组合 |
| relative_tol | 1e-4 | 外层目标相对变化；内层固定代理残差绝对阈值也使用该数值；二者量纲/含义不同 |
| feasibility_tol_mbps | 5e-5 | 原始速率QoS复验容差 |
| acceptance_tol | 1e-5 | 模式目标严格改善门槛；EE与PF数值单位不同 |
| time_limit_s | 90 | 联合搜索的共同预算，传给连续求解及求解器；含建模和求解开销 |
| max_enumeration_k | 6 | 防止指数枚举被当成可扩展算法 |

CLARABEL子问题最多150次迭代，绝对/相对gap和可行性默认容差均为1e-8；`optimal_inaccurate`可以提供待验候选，但不会绕过原约束复验。功率帽检查的容差与设计最小功率检查分别由相应函数控制，均应留在结果诊断中。

时间上限是包含Python建模、矩阵筛查和求解器调用的**软墙钟预算**；剩余时间传给求解器，但程序/数值求解返回的额外开销不支持严格实时截止保证。固定模式超时仍返回最佳已验可行点。联合搜索的最终`runtime_s`覆盖整个调用而非仅最后一个连续子问题；原型不是硬实时控制器。

| 字段/状态 | 正确解读 |
|---|---|
| mode_unavailable | 所选模式不满足当前预测候选策略，不代表已观测真实永久遮挡 |
| nonpositive_precision_margin | 有d_i≤0，当前设计代理固定模式不能通过有限功率达到QoS |
| feedback_radius | \(\rho(F)\ge1\)，固定模式干扰反馈导致设计不可行 |
| power_cap | 最小设计功率超过帽 |
| remaining_subnetwork_infeasible | 切换后迁出/迁入的基底子网不满足条件 |
| schur_or_cap_budget / destination_cap | 迁入反馈或旧/新业务功率帽阻止该切换 |
| design_infeasible | 某一固定模式被设计判据拒绝 |
| certified_design_infeasible | 全部模式确实检查完且均由设计判据拒绝；仅限设计代理 |
| feasible_solution_not_found | 当前启发式/预算未找到可行解；不是全网不可行证明 |
| objective_tolerance_feasible | 目标变化小且有可行点；不是KKT已验 |
| iteration_limit_feasible | 达迭代上限，保留可行点 |
| solver_or_time_limit_with_incumbent / time_limit_feasible | 求解/预算停止，保留已验可行点；查diagnostics区分原因 |
| numerical_stall_feasible | 显著下降候选被拒绝，保留旧点 |
| original_constraints_failed / original_epsilon_constraints_failed | 求解器候选未通过原式复验，记录并拒绝 |
| nonmonotone_proposal_rejected | 数值候选使指定真实目标显著下降，未接受 |
| stationarity_certified=False | 未计算完整KKT证书 |
| global_optimality_certified=False | 没有混合整数全局间隙证书 |

结果中的`feasible`必须和状态字符串、`certificate`及`diagnostics`一起解读。`attempted`保留每个候选的连续迭代history、diagnostics及存在时的epsilon_scan，便于区分筛查拒绝、连续数值停止和有限扫描。尤其有可行incumbent的超时，不是“业务失败”；无可行返回时才在对应方法的业务评价中单独记录未服务。

## 9. 研究原型达到与尚未达到的层次

本轮交付的是可审查的“观测—预测—设计可行性—连续功率—模式候选—原约束复验”链条。理论条件适用于当前固定二阶矩系数和速率代理；独立真实信道上的SINR/速率评价用于暴露模型失配，不把优化代理自证当真实业务保证。

要升级为最终论文代码，还需按实测/可信参数校准参考SNR与功耗、扩展导频周期和接收模型、检验粒子后验条件校准及FOV门槛、报告求解预算敏感性和ε网格敏感性，并视论文主张补足KKT或可认证全局界。是否需要这些扩展应由实际问题与创新边界决定，不能以新增无关维度替代当前机制验证。实验运行结果及失败情况见文件05，本文件不编造任何数值性能结论。

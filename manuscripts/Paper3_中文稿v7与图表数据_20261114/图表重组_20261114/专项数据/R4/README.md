# R4：预测平均能效预算专项数据

此数据包对应冻结方法在 10B、50B 上的预算敏感性分析。每组预先均匀选定 200 个周期，预算取 δ=0.05、0.10、0.20；所选周期及全部版本校验值见 protocol.json。原 1000 周期中的失败记录未据结果排除；本次等距选点未抽中原 10B 第 588 周期或 50B 第 443 周期，这两类失败分支已另作恢复验证。

## 文件与统计对象

- 10B_periods.csv、50B_periods.csv：每文件 600 行，保留全部 200 个计划周期的三档结果。success 仅表示返回满足动作结构与功率范围的完整分配；预测服务和实际服务分别记录。
- R4_plot_summary.csv：每组取三档均返回分配的周期交集。先逐周期计算实际平均 EE 损失百分比 L=100(1−ηavg/ηavg,ref)，以及实际最低链路 EE 增益 G=ηmin−ηmin,ref，再分别计算中位数、P25 与 P75。G 单位为 Mbit/J；区间为两个边际四分位区间。
- R4_planned_service.csv：以每组 200 个计划周期报告求解失败、实际全链路达标、违约链路周期数、预测预算及最终下分位检查。actual_loss_over_own_delta_count 使用各档自身 δ；actual_loss_over_10pct_count 使用共同的 10% 门槛。
- R4_common_periods.json：图中每组共同周期索引。
- independent_array_checks.json：按保存的逐链路速率数组及发射电输入功率独立复算每周期预测/实际 EE 的核对结果。
- analysis_manifest.json：统计公式、协议/驱动程序哈希、400 个正式周期提交校验值、数据输出校验值。
- package_manifest.json：本数据包文件的字节数与 SHA-256。

## 复用与新增求解

δ=0.10 读取已有正式 guarded 方法的同周期完整动作；恢复入口在 10B、50B 各四个有输出周期上重新运行该档，完整动作与预测/执行指标均通过一致性检查。δ=0.05 和 0.20 从同一个冻结的第一阶段动作与参考 EE 各自独立启动完整公平阶段，包括模式比较、NM 连续功率细化、解析联合协调和最终预测检查。各档使用同一条件轨迹；不存在跨 δ 的结果暖启动。

decision_time_s 对两档新增预算记录本次完整公平阶段耗时；δ=0.10 复用已有结果，不填入新增求解耗时。该列不能解读为从信道估计开始的端到端决策时间。

求解阶段使用完整条件信道轨迹在内存中评价，落盘只保存速率小数组和动作，不另存全量信道库。验证目录未参与本数据包统计。

50B 在前 74 个周期提交后改用两个独立周期工作进程，每进程仍为一个数值线程；其后依据空闲内存保护规则自动退回单工作进程，另一项诊断结束并释放资源后，在第149个提交边界恢复两个工作进程。原驱动程序、协议和科学源码保持原 SHA；协调入口直接调用冻结的单周期函数，仅父进程提交输出。两次接管记录与before/after清单验证已提交数据不变，runtime_execution.json 给出实际并发记录和完成状态。各周期从自己的因果检查点恢复，使用 forecast_seed+k 和每次 NM 调用内固定的局部随机种子，分片不改变输入或搜索预算。

# R1：10B导频额外到达时延专项

固定200个预定周期，索引取`floor(i*999/199+0.5), i=0,...,199`。原10B的交通、真实信道、导频时刻、功率、积分时长、观测噪声、预测抽样种子、QoS和δ=0.10保持。额外到达时延取0、5、10、20 ms。

## 因果输入

`run_delay_diagnostic.py prepare`使用一个正式TruthOracle生成全部观测。四个估计器读取同一只读观测数组，只改变导频消费的到达时刻；任何导频在所有估计器均消费后才从共享缓存删除。每100 ms连续更新全部历史，不因只选200个求解时点而跳过滤波更新。

四档在决策时刻具有相同的VLC已到达观测，因此每个周期检查VLC增益均值逐元素相同。该设计研究RF信息年龄改变时的联合分配响应，VLC信息作为固定对照。真实信道与导频噪声均由原随机实现生成，不人为放大后验方差。

RF NMSE域为块初几何候选；VLC域为块初几何候选中满足H≥Hmin的可观测端口，包含所有符合条件的前后端口。域独立于各档所选动作。每个预定时点保存误差平方和、真值平方和及样本数，最后跨时点先求和再取比。

每个时点仅保存小型状态快照、当前真值与域；不保存条件信道轨迹库。条件轨迹在求解时按原种子重建。

## 求解与评价

每档从自身后验重新求解平均EE初始分配，并建立本档ηref；然后执行模式候选比较、NM与guarded解析协调。连续功率和模型参数采用正式代码，科研源码未修改。

固定预测探针使用原0 ms信息下的初始分配与端口，分别记录预测均值、校准下分位和相同真实执行速率。重新优化动作的性能单独记录。所有候选选择结束后才恢复未来真值进行实际评价。

0、5、10号预定周期已完成0 ms基准验证：参考/公平预测样本逐位相同、重新求得参考与完整动作功率差为0、真实100×5速率逐位相同。10B原完整guarded方法在全部周期保留原NM动作，因此这里也与冻结主方法一致；正式参考与主方法数据的映射另见主结果证据包。

## 运行与恢复

1. `run_delay_diagnostic.py prepare --last 999`准备完整输入。
2. `launch_worker.py --shard 0 --workers 2`与`--shard 1 --workers 2`分别处理预定索引的偶数/奇数位置，每个进程1个数值线程。启动器先核对输入、源码哈希和重复进程，后台运行不打开窗口。
3. 每个完成单元以`commit.json`提交；再次启动跳过已提交单元。源文件、当前分配、预测和执行值、失败原因均在每个单元保留。
4. `summarize_delay.py`输出逐周期CSV、各档汇总与固定探针诊断。尚未提交的单元标为pending，不计为求解失败。最终共同求解成功周期用于跨档成对EE比较，各档200个计划周期用于服务计数。

各档汇总只有全部800个单元提交后才是完整结果。中途进度用于运行监测，不用于选择时延档位或调整种子。

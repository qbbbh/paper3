# V11问题分类与修改裁决

本轮以下载保存的V11分章稿为修改前文本。V11已经改正的算法名称、三小节结构和部分图注继续保留；以下列出本轮实际改动及其理由。引文为原段落的连续节选，完整增删见逐段对照文件。模型、优化目标、实验数据与科研代码保持不变。

## 1. 论证与数学表达

| 问题与位置 | 修改前 | 修改后 | 裁决与理由 |
|---|---|---|---|
| **1．贡献不能靠增加求解步骤成立**；引言贡献三 | “设计结合周期速率预测与干扰耦合关系的通信模式搜索和连续功率协调方法。”随后依次介绍连续细化、解析调整和最终评价。 | “设计结合周期速率预测与解析干扰关系的联合求解方法。”并明确：“连续功率细化直接使用周期速率预测，解析速率模型则显式描述各发送功率对期望信号和同方式干扰的影响，为进一步调整功率提供方向。” | **改写贡献的依据，保留真实方法。** QT、NM和最大最小EE都有既有研究，多执行一次搜索不能单独构成创新。本文应说明其研究问题：不完美CSI下的周期评价、固定平均EE参考及允许下降比例、通信模式与发送功率的联合选择；再说明两种功率搜索为何配合。性能增量支持这项设计的作用，不能代替文献比较中的原创性论证。 |
| **2．摘要的因果关系与决策对象**；摘要 | “车辆运动使V2V通信中的信道增益与干扰在传输期间持续变化，信道估计误差又使决策时获得的信息偏离真实信道。” | “车辆运动使接收信号和链路间干扰在传输期间变化，导频观测误差与到达时延进一步限制了信道状态信息的准确性。因此，仅依据决策时刻的信道估计值分配资源，难以评价整个通信周期的传输性能。” | **把问题说明白，再引出预测。** 明确车辆运动改变传输条件，观测误差和时延影响决策信息；两者共同解释为何要评价整个通信周期。平均EE不能保证最低EE改善另起一句，不把两条动机压成术语串。 |
| **3．发送功率属于车辆，链路编号用于索引**；II-A、IV节首 | “系统根据车辆的位置、速度、航向及已到达的导频观测，选择通信车辆、发送方向、RF/VLC方式和发送功率。” | “系统根据车辆运动信息与导频观测，联合确定通信模式和发送车辆的电输入功率。通信模式规定哪些车辆相互通信、谁向谁发送，以及采用RF还是VLC。” | **采纳对象明确的要求，保留已有数学符号。** 第二节直接定义$p_\ell$为发送车辆$i_\ell$的数据发送电输入功率。每个发送车辆在当前周期只参与一条链路，因此使用链路下标并无数学错误，无需重命名整套功率变量。数据电输入、RF导频辐射输出和VLC导频光输出仍分别定义。 |
| **4．校准分位的含义不能用删词替代**；IV-A | “它反映较低速率情形，不是最低样本值，也不是最差5%样本的平均值。采用以下校准预测速率检查最低服务要求……” | “为评价低速率情形，取$q=0.05$，由样本估计预测速率分布的5%分位数$Q_\ell(q)$，即划分最低5%速率的阈值。在此基础上定义校准预测速率，并用它检查最低速率要求……” | **删去连续否定式解释，保留实际筛选规则。** 首次出现时用“阈值”说明含义，随后统一称“校准预测速率”。将其直接改为预测均值或笼统的“校准速率”，却不保留定义，会改变或掩盖方法。业务门限与平均EE约束属于所求问题的必要内容，在定义处集中说明即可。 |
| **5．横线与帽号不强行统一**；II-C、III-C | “下文用横线表示时间平均，用帽号表示根据可用信息得到的估计或预测；实际值与预测值采用相同的EE定义。” | “下文用横线表示时间平均，用帽号表示根据可用信息得到的估计或预测；预测EE与实际EE采用相同定义，分别以预测速率和实际速率计算。” | **保留不同数学运算的符号，补足两者关系。** 周期时间平均与根据信道信息得到的预测不是同一操作，不能因视觉统一而合并。III-C还将累计相关系数明确为观测至决策区间内各步相关系数的乘积，用具体时间间隔说明信息变旧的影响。 |
| **6．CRLB分析对象须准确**；III-B | “Cramér–Rao下界（CRLB）描述给定观测模型能够达到的估计精度[24]。” | “Cramér–Rao下界（CRLB）给出无偏估计的误差下界[24, Chs. 3 and 15]。”随后给定确定参数、几何条件、导频设置和正的噪声方差。 | **纠正‘下界必然可达’的暗示。** CRLB一般给出下界，具体观测模型中是否可达另作判断。当前单次观测下界与利用历史观测的递推估计不是同一对象。正文保留紧凑条件与Fisher信息结果，不增加一套无关的Bayesian界。 |
| **7．第三、四节需要真实的统计量接口**；IV-A | “根据第三节的状态均值和方差抽样，按照式（5）、（7）推进信道状态，并外推车辆位置……” | “根据式（19）—（21）得到的决策时刻状态均值与方差，抽取RF阴影状态、复衰落系数及VLC对数光强状态，再按式（5）、（7）生成$S$组周期内的信道变化样本。车辆位置根据当前运动信息外推……” | **补准确式号和物理对象。** 状态统计量构成预测输入，平均信道增益用于解析功率问题，二者不能互相替代。随机状态传播与车辆位置外推分别说明，读者不必返回代码寻找预测从何而来。 |
| **8．二次变换须说明具体数学动作**；IV-C1、C2 | “采用二次变换[25]处理有效SINR中的分式。”以及“对平均EE中的速率功耗比再次应用二次变换……” | “为建立便于联合求解的功率子问题，采用二次变换[25]，将有效SINR改写为关于辅助变量的等价最大化形式……”；随后写明“平均EE是各链路速率与功耗之比的算术平均；仅改写SINR尚未消除这一层比值”，并给出第二层恒等式。 | **两类比值分别解释。** $y_\ell$用于SINR，$b_\ell$用于速率与功耗之比；$s_\ell^2$受速率下界约束。式（34）之后说明固定辅助变量时的仿射目标和凸约束，使读者知道变换为何有助于求解，而非只看到方法名称。 |
| **9．两个阶段与循环规则清楚对应**；算法1 | 第2—6行给初始求解，第7—12行给公平候选、NM及解析调整，但没有阶段标签；“按周期预测择优”未在算法中给比较量。 | 增加“第一阶段：平均EE参考分配〔式（28）〕”与“第二阶段：平均EE约束下的公平分配〔式（29）〕”；第3行写“按服务达标、服务总缺口、预测平均EE的顺序保留当前分配”。 | **压缩重复操作，保留决定输出的顺序。** 算法为15个编号步骤；初始搜索后的末端功率细化、服务修复、参考EE固定、多起点NM和固定插值基点均保留。公平阶段始终使用第一阶段返回后确定的参考值，不能把该条件提前套到第一阶段。 |
| **10．附录入口必须有实际定义**；IV-C与附录A | “初始功率与目标$\theta$的有限搜索见附录A。” | “先由式（A4）构造初始功率，再在式（A5）给出的范围内试探$\theta$：原解析速率达到目标时提高门限，否则缩小试探区间。” | **从附录名称落实到实际公式。** 固定能耗分母的初始化、固定门限功率子问题及原解析速率检查分别说明。附录A补齐初始化功率及取点分布、内部速率修复和比较规则；统计样本数、设备与计时记录移回实验说明及随稿数据说明，不混入求解推导。 |
| **11．附录凸性证明限定真实数学对象**；附录B.1 | “在本文信号和噪声模型的有效定义域内，固定辅助量后的式（34）、固定$\theta$后的式（36）均为凸优化子问题。” | “对于式（9）—（12）的RF/VLC模型，固定辅助变量后的式（34），以及固定$\theta>0$、在$1+A_\ell^{(r)}>0$内的式（36），均为凸优化子问题。” | **把笼统条件写成可检验条件。** 二次变换的平方差证明给出下界与紧性；信号项为正且可微时给出一阶一致性。RF的$\sqrt S$为凹函数、$D$为仿射函数；VLC的$\sqrt S$为线性函数、$D$为凸函数，据此证明子问题结构。该结论属于固定辅助量的解析子问题，不扩大为整个离散搜索的全局最优结论。 |
| **12．误差分析应给明确关系**；附录B.2—B.3 | “式（B4）表明，预测中的最低EE改善和平均EE约束余量都需要与速率误差的影响相比较……” | “当$\widehat G\ge E_{\mathrm{avg}}^a+(1-\delta)E_{\mathrm{avg}}^0$时，实际平均EE也满足相对于参考分配的下降约束；当预测最低EE增量超过$E_{\min}^a+E_{\min}^0$时，实际最低EE相应提高。” | **由界推出具体充分条件，替换泛泛总结。** 候选与参考分别采用其误差界，$0\le\delta\le1$；周期误差传递使用相同时间积分或采样。这里的条件误差上界并非由单次观测CRLB给出，亦未作为新约束加入算法。误差除以发送功耗后影响EE，解释了相同速率偏差在不同链路上的不同后果。 |

## 3. 保留与未新增的内容

- 保留“弱链路优先”的搜索思想，以及它指向低EE链路的解释。精确排序不作为正文论证的中心。
- 保留50车与MMEE-FP之间的效率取舍及全部对照数据，不增加逐项不足清单，也不写成所有指标全面领先。
- 本轮没有新增仿真或改变算法。关于50车时延与更高业务需求的建议单列于《09_后续验证建议_未执行.md》，不进入现有结果和结论。

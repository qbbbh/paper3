# 符号、公式编号与参数引用说明

本文件记录V11修订稿中容易混淆的数学对象、公式位置及参数依据，供作者核对。正文模型、实验数值和科研代码未因本轮文字整理而更换。文献书目、具体参数来源和本文计算结果分别核对；查到书目不等于已核对该文献的全部内容。

## 一、保留的符号区别

| 符号或对象 | 本文含义 | 处理及理由 |
|---|---|---|
| $x_{ij}^{m}$、$\boldsymbol x$ | 谁向谁发送，以及采用RF还是VLC | 保留第二节已有定义；通信模式不被缩窄为单独的RF/VLC选择。 |
| $p_\ell$ | 链路$\ell$对应发送车辆的数据发送电输入功率 | 链路编号是索引，物理上由发送车辆控制。正文统一说明这一点，避免“链路发射功率”造成对象误解。 |
| $\varepsilon_m p_\ell$ | RF辐射功率或VLC光输出功率 | 与电输入功率区分。EE分母使用$P_{c,m_\ell}+p_\ell$，不再除一次转换效率。 |
| $P_{p,m}$ | 导频输出功率 | RF为辐射功率，VLC为光功率；不与数据发送电输入功率混用。 |
| $g_{ij}^{\mathrm{RF}}$ | 包含路径损耗、阴影和复衰落幅度平方的RF功率增益 | 第四节代入SINR的是功率增益均值，不是复幅度均值。 |
| $h^{\mathrm{RF}}$ | 第三节除去几何路径损耗后的RF复幅度 | 与RF功率增益有不同的量和估计对象。单次RF观测CRLB针对该复幅度的实部和虚部。 |
| $H_{ij}^{uv}$、$h_{ij}^{uv}$ | VLC几何光增益、加入随机光强后的光增益 | 由式（6）和式（7）定义；保留大写、小写的区别。 |
| $P_{r,0}$、$P_r$ | 几何光增益对应的导频接收光功率、包含随机光强后的接收光功率 | 观测方差按$P_{r,0}$计算；不能把它在推导中替换为依赖待估状态的$P_r$。 |
| $r_\ell(t)$、$\overline R_\ell$ | 瞬时速率、一个通信周期内的时间平均速率 | 横线表示时间平均；实际EE由实际周期平均速率计算。 |
| $\overline R_\ell^{(s)}$、$\widehat R_\ell$ | 第$s$条预测轨迹的周期平均速率、全部预测轨迹的样本均值 | 样本上标与帽号承担不同作用。不能为了外观统一而把二者合成同一符号。 |
| $Q_\ell(q)$、$\widetilde R_\ell$ | 预测速率的$q$分位数、经式（27）校准后的服务检查速率 | 分位数是分界值，不是最低$q$比例样本的均值；校准速率也不是预测均值。首次出现处解释，后文用已定义名称。 |
| $\widehat\eta_\ell$、$\eta_\ell$ | 预测链路EE、实际链路EE | 两者采用相同功耗分母，速率输入不同。预测平均EE约束与实际表现分别报告。 |
| $\eta_{\mathrm{ref}}$ | 第一阶段最终返回分配的预测平均EE | 在第二阶段保持不变；不随NM或解析协调更新，也不解释为第一阶段问题的全局最优值。 |
| $\tau_{ij}$、$\tau_v$、$\tau_o$ | RF快衰落相关时间、VLC对数光强相关时间、最近可用观测至决策时刻的时间间隔 | 三者保留各自下标与定义。正文不再单独使用含义不明的“年龄”。 |
| $\xi_{ij}(t)$、$\xi_\ell$ | RF复高斯驱动噪声、NM对数功率变量 | 不同索引和使用章节可区分，NM处单独给出与功率的关系；没有把噪声样本带入功率优化。 |
| $S$、$S_\ell(\mathbf p)$ | 预测轨迹数、解析接收信号项 | 一个是样本数量，一个是带链路索引的函数；在各自首次使用处定义。 |
| $d_m$、$d_\ell(\mathbf p)$、$d_{ij}$ | 导频到达时延、EE功耗分母、车辆间距离 | 保留已有符号以避免全稿重命名，并在定义处明确单位与物理对象。 |

第三节的RF顺序更新采用独立高斯近似。式（21）的有效观测方差承担这一近似更新的作用，不等同于完整联合后验。式（22）—（23）分析单次观测下的确定参数无偏估计；利用先验和历史观测的递推方差由式（19）—（21）计算。

## 三、表I参数的依据

分类含义：**文献取值**表示原表可核到相同数值；**按文献数据计算**表示本文从已核数值运算得到；**本文设置**表示本轮未找到支持同一具体数值的外部原文，不给它补挂相似文献。

| 表I项目 | 当前数值 | 分类与直接依据 |
|---|---|---|
| 通信带宽 | RF 22 MHz；VLC 50 MHz | 本文设置。Luo文献[22]表3的VLC带宽为2 MHz，不能支持本表50 MHz。 |
| 发送电输入功率范围 | RF 0.01–20 W；VLC 0.1–30 W | 本文设置；与当前冻结配置一致。本轮未核到同一范围的外部出处。 |
| RF转换效率 | 0.10 | 文献取值。[27]第8页Table 2列出功率放大效率0.1。 |

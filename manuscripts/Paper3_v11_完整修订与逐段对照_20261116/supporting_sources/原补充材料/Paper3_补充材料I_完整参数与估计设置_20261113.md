# 补充材料I　完整参数与估计设置

本材料与正文v9配套。数据文件中的R1、R2、R3、R4分别对应当前图1、图2、图4、图5；图3与图6由同一批分方式和服务计时记录绘制。原数据文件名保留以便复现。

本材料列出数据链路、接收噪声、信道状态、导频观测及数值求解的完整设置。表中参考文献以上标标于对应数值之后；未标外部文献的参数为本文设置或由已列参数计算的派生量，物理常数另注明。符号与正文一致，未单独定义符号的设置以“—”表示。服务修复、候选比较与功率初始化见补充材料II，详细结果与统计口径见补充材料III。

数据发送功率$p_\ell$以电输入计，导频功率$P_{p,m}$分别以RF辐射输出和VLC光输出计。链路EE为$\overline R_\ell/(p_\ell+P_{c,m_\ell})$，平均EE为活动链路EE的算术平均，最低EE先在每个周期内对活动链路取最小值。固定导频方案用于确定观测质量，其输出能量单独记录，不直接加入上述电输入功耗分母。

## 2. 接收噪声及派生数值

**表I-2　接收噪声参数**

| 物理意义 | 符号 | 数值 |
|---|---|---|
| RF基准带内噪声 | — | −95 dBm（10 MHz带宽内） |
| RF等效噪声谱密度 | $N_0^{\mathrm{RF}}$ | $3.1623\times10^{-20}$ W/Hz |
| RF实际带内噪声 | $N_{\mathrm{RF}}$ | $6.9570\times10^{-13}$ W（22 MHz带宽内）（−91.5758 dBm） |
| 背景光电流 | $I_{\mathrm{bg}}$ | 5.1 mA<sup>[22]</sup> |
| 接收器温度 | $T_r$ | 298 K<sup>[22]</sup> |
| 放大器开环电压增益 | $G$ | 10<sup>[22]</sup> |
| 单位面积电容 | $C_A$ | $1.12\times10^{-6}$ F/m²<sup>[22]</sup>（112 pF/cm²） |
| 总输入电容 | $C$ | $1.68\times10^{-10}$ F |
| FET噪声因子 | $\Gamma_n$ | 1.5<sup>[22]</sup> |
| 跨导 | $g_m$ | 0.03 S<sup>[22]</sup> |
| 噪声带宽因子 | $I_2,I_3$ | 0.562、0.0868<sup>[22]</sup> |
| 电子电荷 | $q_e$ | $1.602\times10^{-19}$ C |
| 玻尔兹曼常数 | $k_B$ | $1.380649\times10^{-23}$ J/K |

RF基准值−95 dBm对应10 MHz带宽。保持有效噪声谱密度不变，得到

$$
N_0^{\rm RF}=\frac{10^{(-95-30)/10}}{10\times10^6}
=3.16227766\times10^{-20}\ \mathrm{W/Hz},
$$

$$
N_{\rm RF}=N_0^{\rm RF}\,22\times10^6
=6.95701085\times10^{-13}\ \mathrm W,
$$

即22 MHz带宽内−91.5758 dBm。该量表示本文设定的有效接收噪声。

表I-2中的电子电荷与玻尔兹曼常数采用所列物理常数值。VLC总输入电容为$C=C_AA_{\rm PD}=1.68\times10^{-10}$ F。噪声器件参数来自文献[22] Table 3，$I_2$、$I_3$同时参见该文式(20)后的说明。背景散粒和热噪声方差按

$$
\sigma_{\rm bg}^2=2q_eI_{\rm bg}I_2B_{\rm VLC},
$$

$$
\sigma_{\rm th}^2=\frac{8\pi k_BT_r}{G}CI_2B_{\rm VLC}^2
+\frac{16\pi^2k_BT_r\Gamma_n}{g_m}C^2I_3B_{\rm VLC}^3
$$

计算。背景散粒噪声为$4.5916524\times10^{-14}$ A²，热噪声两项分别为$2.44075964\times10^{-15}$ A²和$9.94804133\times10^{-15}$ A²，基础噪声之和为$5.83053250\times10^{-14}$ A²。

完整噪声还包括式(12)中的信号散粒项

$$
\sigma_{\rm sig,\ell}^2(t)
=2q_e\varrho B_{\rm VLC}\sum_{b:m_b=\mathrm{VLC}}O_{b\ell}(t).
$$

接收总光功率前的系数为$7.209\times10^{-12}$ A²/W；求和同时包含期望发送者和同模式干扰发送者。基础噪声是常数，完整噪声则随通信模式、功率和信道变化。

## 4. 导频观测与递推估计

**表I-4　导频观测与估计参数**

| 物理意义 | 符号 | 数值 |
|---|---|---|
| 固定导频输出功率 | $P_{p,m}$ | RF：2 W辐射功率；VLC：2 W光输出功率 |
| 导频观测周期 | $\Delta_m$ | RF：1 ms；VLC：50 ms |
| 观测到达时延 | $d_m$ | RF：2 ms；VLC：5 ms |
| 单车单次导频时长上限 | — | RF：1 ms；VLC：1 ms |
| 名义导频资源预算 | $b_{\mathrm{pil}}$ | RF：0.20；VLC：0.20 |
| 10车单次积分时长 | $T_{p,m}$ | RF：20 μs；VLC：1 ms |
| 50车单次积分时长 | $T_{p,m}$ | RF：4 μs；VLC：0.2 ms |
| 10车单次导频输出能量 | $E_{p,m}$ | RF：40 μJ；VLC：2 mJ |
| 50车单次导频输出能量 | $E_{p,m}$ | RF：8 μJ；VLC：0.4 mJ |
| 对数域观测噪声标准差下限 | $\sigma_0$ | VLC：0.12 |
| VLC可观测几何光增益门限 | — | VLC：$10^{-8}$ |

每种方式的名义导频资源预算为$b_{\rm pil}=0.20$。沿用第三节的$P_{p,m}$与$T_{p,m}$，单车单次导频积分时长设置为

$$
T_{p,m}=\min\left(1\ \mathrm{ms},\frac{b_{\rm pil}\Delta_m}{N}\right),
\qquad E_{p,m}=P_{p,m}T_{p,m}.
$$

RF导频功率2 W按辐射输出计，VLC导频功率2 W按光输出计，分别用于式(16)和式(17)。表I-4中的导频输出能量由功率与积分时长相乘得到。每种通信方式分别采用20%的名义导频资源预算及批量观测模型；式(13)评价数据传输的毛速率。导频输出能量与数据发送支路的电输入能耗分别记录。

VLC观测在几何光增益满足可观测条件时用于状态更新，其余时刻按式(19)预测。$\sigma_0=0.12$将单次对数观测的噪声方差下限设为$0.0144$。递推估计融合先验和历史观测，后验方差由式(20)计算。

RF滤波器以裁剪后的时间常数$\tau_{ij}$反算有效速度

$$
\widetilde v_{ij}=\frac{0.423\lambda}{\tau_{ij}},\qquad
\rho_{s,ij}^{\rm est}=\exp\left(-\frac{\widetilde v_{ij}\Delta t}{d_s}\right).
$$

生成执行信道和条件信道轨迹时，则使用

$$
\rho_{s,ij}=\exp\left(-\frac{v_{ij}^{\rm rel}\Delta t}{d_s}\right).
$$

相干时间未触及限幅时，两者一致；触及限幅时，估计器与信道过程按各自系数递推。相干时间近似参考[21]，时间常数限幅及反算速度属于本文估计设置。正文中的递推估计按第三节给出的RF两状态近似更新和VLC对数状态更新执行。

## 6. 随机实现、计时与结果记录

交通基础种子为20261019。A、B信道种子分别为2026102401和2026102801，条件预测基础种子为2026102501并按通信周期编号递增。同一规模的A、B共用交通轨迹和物理模型，仅采用不同的信道随机实现；10车与50车分别使用相应规模的交通轨迹。

10车完整流程使用1线程，50车完整流程使用2线程，保存场景上的追加计算每进程使用1线程。计算成本分别记录完整决策和主要阶段耗时，并区分完整运行与追加计算。给定交通、信道轨迹上的离线评价不把求解等待时间计入车辆运动时钟。

初始阶段是否启用均值后备、最终动作是否回到第一阶段返回动作、最终下分位服务检查结果，以及未获得可执行动作的失败周期，分别保留。实际服务满足情况和平均EE损失根据执行信道评价，与预测预算分开统计。

各方法的成功周期数、共同成功周期比较、服务表现与功率统计见补充材料III。

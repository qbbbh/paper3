# 基础层：CRLB 的作用与适用边界

日期：2026-10-23
数据来源：`代码/基础层_通信与信道估计_20261023/crlb_report.py`（可复现）、
`results/crlb_role_n10.png`、`results/crlb_role_n10.json`、
`results/channel_trace_n10_3to8*.csv`（1 ms / 20 ms 导频，100 s，n=10，链路 3→8）。
场景：10 车，5.89 GHz，22 MHz，N0 = −165 dBm/Hz，RF 导频时隙 20 µs（1 ms 周期、20% 预算）。

> **2026-10-23 更正（优先于下文）：** 第 3 节的 3.66 / 5.94 dB 是**特定预测器在给定精确初始状态下的模拟 RMSE**，
> 不是 dB 域的后验 Cramér–Rao 界（dB PCRB）。两状态 RF 模型是非线性的（观测 `y = exp(L/2)·a + n`），
> 当前实现还丢弃交叉相关、对强度观测作近似更新、输出分位时又矩匹配为复 Gaussian，
> **不能套用线性高斯的可达性结论**。因此下文第 0、3.3、6、8 节中"已经到界""没有改进空间"
> "全部误差来自年龄"的说法**予以撤回**：它们是对特定预测器与 CSI 年龄关系的实测描述，不是最优性证明。
> 严格的复合信道 PCRB 与同对象 MSE 验证仍是后续理论任务。
> **第 2 节观测界（经典 CRLB，匹配滤波可达）不受影响，仍然成立。**
> 修订后的口径见 `代码/交接_同学_50_100车开发_v2_20261023/04_CRLB的作用与适用边界.md`。

## 0. 一句话结论

**CRLB 在本论文里只回答两个问题：导频给够没有、观测环节的估计还能不能更好。它不进入资源分配。**

- 观测环节：2 W / 20 µs 时近端链路 CRLB = 4.6×10⁻⁴ dB，实测 0.001 dB —— **匹配滤波已达到经典 CRLB，这一项没有改进空间**。
- 预测环节：2 ms 年龄实测 3.83（复合 AR(1)）/ 3.70（两状态）dB；3.66 dB 是**线性高斯模拟参照**。
  两状态是非线性模型，3.66 不是它的 dB PCRB，**不能据此说"也到界了"**（见开头的更正）。
- 误差随 CSI 年龄单调增长（2 ms 约 3.7 dB → 20 ms 约 5.3 dB），年龄是主要可控因素；
  但"误差全部来自年龄"是一句归因描述，**不是最优性结论**。
- 资源分配拿到的是**条件分布**（`rf_gain_low/high` 分位数），不是任何一个 CRLB 数。

## 1. 三个量必须分开，不能互相替代

| | 观测界 | 预测参照 | 决策输入 |
|---|---|---|---|
| 估计对象 | 导频时刻的 h | Δ 秒后的新样本 h(Δ) | 本块平均 SINR / 速率的分布 |
| 已知信息 | 当前导频 | 全部历史观测 | 全部历史观测 + 几何 + 功率 |
| 数学对象 | 经典 CRLB（确定性参数） | 贝叶斯后验协方差（线性高斯下精确） | 条件分布的分位数 |
| 公式 | Var ≥ N0/E_p | V(Δ)=ρ²P⁺+(1−ρ²)P∞ | `rf_gain_low/high` |
| 谁达到 | 匹配滤波，本层已达到 | **仅线性高斯下** Kalman-MMSE 可达；两状态是否达到未经 PCRB 验证 | 由资源分配层使用 |
| 用途 | 定导频预算 | 归因、判断还有没有改进空间 | 约束与目标 |

**最常见的误用是把第一行当成第三行**：拿一个 dB 精度的 CRLB 当"CSI 误差半径"，再乘个系数当 QoS 安全裕量。这个做法没有依据（见第 4 节）。

## 2. 观测界

### 2.1 公式

导频接收：`r = √E_p · h + w`，`Var(w) = N0`。匹配滤波后 `ỹ = h + w̃`，`Var(w̃) = N0/E_p = R`。
这是复高斯噪声下确定性参数的经典 CRLB，匹配滤波估计量**恰好达到**（效率 = 1）。

dB 域（10·log10|h|²，归一化 |h| = 1）：

```
sd_dB = (10/ln10)·√(2R) = 6.14·√R
```

### 2.2 数值（n = 10，1 ms 周期，20 µs 时隙）

| 导频功率 | E_p/N0 | 8.7 m 链路 | 100 m 链路 |
|---:|---:|---:|---:|
| 2 W | 82.6 dB | 4.6×10⁻⁴ dB | 5.5×10⁻² dB |
| 0.2 W | 72.6 dB | 1.5×10⁻³ dB | 1.7×10⁻¹ dB |
| 0.02 W | 62.6 dB | 4.6×10⁻³ dB | 5.5×10⁻¹ dB |
| 2 mW | 52.6 dB | 1.5×10⁻² dB | 1.7 dB |
| 1 mW | 49.5 dB | 2.1×10⁻² dB | 2.4 dB |

全部 90 条候选链路（2 W / 20 µs）：p10 = 6.8×10⁻⁴ dB，**p50 = 1.4×10⁻² dB**，p90 = 4.8×10⁻² dB，最差 5.8×10⁻² dB。

规模（2 W，1 ms 周期，固定 20% 空口预算）：

| n | 时隙 | 近端 CRLB |
|---:|---:|---:|
| 10 | 20 µs | 4.6×10⁻⁴ dB |
| 50 | 4 µs | 1.0×10⁻³ dB |
| 100 | 2 µs | 1.5×10⁻³ dB |

### 2.3 由此得到的两个结论

1. **在 10/50/100 车规模下，观测环节都不是瓶颈。** 即使规模到 100 车、时隙压到 2 µs，最差候选链路的观测误差也只有 0.058 dB，比 2 ms 老化的 3.7 dB 小两个数量级。
2. **导频功率不能一刀切降到数据功率下限。** 近端链路降到 1 mW 仍是 0.02 dB；但**最远的 100 m 候选链路在 1 mW 下是 2.4 dB**，与老化同量级。所以正确的设计规则是"导频功率按最差候选链路定，或做功率控制"，而不是"导频功率 = 数据功率"。

> 这同时回应了"2 W 导频 vs 1 mW 数据"的不自洽：不自洽确实存在（导频平均功耗 40 mW，1 mW 数据链路时差 40 倍），但**结论不依赖它**——只要导频功率保持在最差候选链路能测到的水平，观测就永远不是瓶颈。

### 2.4 82.5 dB 的正确分解（更正）

旧文档里写的"带内 SNR 35–40 dB"是错的。正确口径：

- 22 MHz 内噪声 = −91.6 dBm，`N0 = −165 dBm/Hz`
- 8.7 m 链路几何增益 −68.47 dB，2 W = +33.0 dBm → 接收导频 **−35.5 dBm**
- 22 MHz 内 SNR = **56.1 dB**
- 20 µs 相干积累增益 = 10lg(22×10⁶ × 20×10⁻⁶) = **26.4 dB**
- 合计 **82.5 dB** ✓

用 10 MHz 口径算（SNR 59.5 dB + 积累 23.0 dB）同样得 82.5 dB。**两套口径不能混用**；混用正是旧说法出错的来源。

## 3. 预测误差参照（线性高斯模拟，不是 PCRB）

### 3.1 公式

给定导频时刻的精确状态，Δ 秒后：

```
V(Δ) = ρ(Δ)²·V⁺ + (1 − ρ(Δ)²)·V∞
ρ(Δ) = exp(−Δ/τ)
```

线性高斯模型下 Kalman 后验协方差**就是**精确的贝叶斯下界（PCRB 在此特例下可达），不需要额外近似。
**但这句话只对线性高斯状态空间成立。** 本层默认的两状态 RF 模型不是线性高斯，当前实现也不是严格后验，
所以第 3.2 节的数值只能当**预测器模拟参照**，不能称为 dB PCRB，更不能用来证明"估计器已达最优"。

**关键点：预测的是条件均值功率 `E[|h(Δ)|²|I]`，不是 `|E[h(Δ)|I]|²`。** 后者在 ρ→0 时趋于 0，dB 会发散；前者趋于先验均值功率，dB 误差收敛到 `√(5.570² + 2.507²) = 6.11 dB`。资源分配需要的正是前者。

### 3.2 数值（预测器模拟 RMSE，不含观测噪声；**不是 dB PCRB**）

| 年龄 Δ | τ = 30 ms（3→8，实测相对速度 0.72 m/s） | τ = 2 ms（典型对向） |
|---:|---:|---:|
| 1 ms | 2.89 | 5.62 |
| 2 ms | 3.66 | 6.02 |
| 5 ms | 4.73 | 6.15 |
| 20 ms | 5.94 | 6.14 |
| ∞ | 6.14 | 6.14 |

3→8 链路 100 s 内实测：距离中位 8.68 m，相对速度中位 0.72 m/s，**τ 中位 30.0 ms**（p10 4.3 ms，p90 500 ms，已触上界）。

> 上表是"给定精确初始状态、按线性高斯近似预测、再取条件均值功率的 dB 误差"的模拟值。
> 它回答"在这个近似下、这个年龄大概会差多少"，**不回答"最好的估计器能做到多少"**。
> 两状态模型的严格 PCRB 需要处理非线性观测与因子相关，尚未推导。

### 3.3 实测对照（n=10，100 s，链路 3→8，同一真值场）

| 导频周期 | CSI 年龄 | 块初直接用观测 | 复合 AR(1) | 两状态 | 模拟参照 | 90% 区间覆盖率（复合 / 两状态） |
|---:|---:|---:|---:|---:|---:|---:|
| 1 ms | 2 ms | 4.05 dB | 3.83 dB | **3.70 dB** | 3.66 dB | 85.8% / **89.2%** |
| 20 ms | 20 ms | 6.02 dB | 5.46 dB | **5.27 dB** | 5.94 dB | 84.7% / **88.9%** |

> 覆盖率按 1000 个块统计，块间强相关（同一轨迹、同一链路），有效样本远少于 1000，
> 只能判断"是否明显偏离"，不能当精确置信区间。VLC 的覆盖率为 90.7%。

- 1 ms 配置下两状态估计器与线性高斯模拟参照只差 **0.04 dB**；这只能说明它**在该参照下没有明显余量**，
  不能推广成"两状态模型已达最优"。
- 复合 AR(1) 比两状态差 0.13–0.19 dB，原因是它每 1 ms 都把阴影信息按快衰落的相干时间丢掉一部分。
- 20 ms 行实测低于参照值，是因为参照按 τ=30 ms 的集合平均给出，单条轨迹可以上下波动；这**不**说明估计器超过了参照值，参照本身也不是严格下界。

**结论：在线性高斯参照下，1 ms 导频的预测误差已接近该参照，继续改估计器的边际收益很小；
但两状态模型的严格 PCRB 尚未推导，所以"已经到界"不能作为论文结论。** 误差主要由年龄决定，
而年龄 = 导频周期 + 时延——这一点有实测支持。

覆盖率这一列还说明另一件事：复合 AR(1) 把阴影方差当成了快衰落的平稳方差，**预测区间偏窄**，
标称 90% 只覆盖 84.7–85.8%；两状态回到 88.9–89.2%。覆盖率不达标不是"估计不准"，
而是**模型设定错了**。如果 QoS 约束要用分位数，必须用两状态的区间。

## 4. CRLB 为什么不能直接进资源分配

四条理由，缺一不可：

1. **对象不同。** CRLB 描述"给定观测、估计**同一时刻**参数"的方差；资源分配需要的是"决策时刻到块末、**未来样本**的分布"。
2. **它是下界，不是估计。** 优化器需要一组可用的 CSI，或一个可采样的分布；一个方差下界不能当信道值代入速率公式。
3. **它是方差，不是分位数。** QoS 约束是 `Pr(R̄ < R₀) ≤ ε`，需要条件分布的 `ε` 分位数；方差只够做二阶近似，且对重尾（Rayleigh 的 dB 域）不准。
4. **把它当误差半径会造出不可达约束。** "CSI 误差 ≤ CRLB 的 k 倍"没有任何定理支撑；实际误差可以远大于界。

所以本层的接口是 `rf_gain_mean / rf_gain_low / rf_gain_high`（条件分位数），不是 CRLB。

## 5. CRLB 在本文的三个正当用途

1. **定导频预算。** 给定目标观测精度 `sd_dB`，反解所需导频能量：
   `E_p ≥ N0·(sd_dB/6.14)²`。这条直接支撑"1 ms / 20 µs 够用"的实现假设。
2. **规模论证。** n = 10/50/100 的观测界只从 4.6×10⁻⁴ 涨到 1.5×10⁻³ dB，说明**规模变大不需要换观测模型**；三个规模可以共用一套估计器与接口。
3. **误差归因。** 把总误差拆成"观测界（真界）+ 年龄造成的预测误差（模拟参照）"，用一张图说明改进空间在哪。这也是第 3、4 项验收（区间覆盖率、块平均速率）的解释框架。

## 6. 与第 3 篇原论文、ai2 意见的对应

| 议题 | 处理 |
|---|---|
| 原论文 `Q_m = σ²_VLC·I` | 本层 RF 用 `N0/E_p` 归一化；VLC 用**对数域**，SNR 由 `(R·P_r)²/σ²·B·T` 给出。避免了 `σ²` 是 A²、状态是归一化增益的量纲错误 |
| 观测误差只有 0.001 dB | 是 82.5 dB 的 E_p/N0 的直接结果，不是调出来的；且已用 CRLB 验证 |
| "要不要把噪声调大一点" | **不调**。结论不依赖它；调大反而是造数据 |
| 论文重点从"导频去噪"转向"CSI 老化" | 与已定的 Module A（误差与 CSI 年龄感知的可靠服务评估）一致，数据支持明确 |
| 要求加 PCRB 新估计器 | **暂不加**。线性高斯下 Kalman 已精确达到后验界；两状态是非线性模型，严格 PCRB 尚未推导，属后续理论工作。当前实测没有显示明显的改进空间，但这不等于已证明最优 |

## 8. 一句话给论文

> 在本文的导频预算下，观测环节的误差已达到经典 CRLB（4.6×10⁻⁴ dB）；决策误差随 CSI 年龄增长（2 ms 时约 3.7 dB，20 ms 时约 5.3 dB，两状态估计器实测）。因此本文的改进重点不在估计器，而在**老化误差如何进入块平均速率的可靠评价**，以及**用条件分布而非点估计做决策**能挽回多少损失。

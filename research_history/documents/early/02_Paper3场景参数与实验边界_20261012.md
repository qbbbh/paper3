# Paper3场景参数与实验边界

日期：2026-10-12。Paper3工作快照；公共原本为[当前参数与状态v2.0](../../大论文/思路与探讨/当前参数与状态_v2.0_20261012.md)。已定表示作者选择或当前首轮基准，不表示完成物理验证。

更新：2026-10-13。明确最低QoS保障的研究定位；本轮不改变数值参数、时间尺度或并发规则。

## 1. 已确定的骨架

| 项目 | 当前设置 | 边界 |
|---|---|---|
| 主任务 | 估计信息下的复合链路选择与连续功率数值优化 | 具体求解方法未定，不做RL、不做路由 |
| 车辆规模 | 6—10车起步，建议首轮6/8/10 | 主算法不穷举；20车扩展尚为建议 |
| 路网 | 40 m × 40 m 单十字路口及外围闭合道路，车辆持续循环 | 2026-10-14 与现有 SUMO 数据同步；固定数量，不在边界瞬移，不采用驶出后同编号补车 |
| 光学端 | 前后各1个等效LED、1个等效PD | 位置质点、保留航向；不分析左右灯具MIMO |
| 发送方向 | 向前接收车：前LED -> 后PD；向后接收车：后LED -> 前PD | 其他相对位置按统一几何规则；不要求双端同时通信 |
| 传播 | 晴天车用VLC路损简化，优先复用AEÜ2025所引Karbalayghareh模型 | 说明等效前后端简化，不新增灯具拟合，不把前灯拟合当尾灯实测 |
| 遮挡 | 简明直达路径车体遮挡，期望信号和干扰同规则 | 车体包络尚待配置，不手动把所有同车道干扰置零 |
| 候选业务 | RF搜索100 m；VLC方式上限45 m并检验方向/FOV/遮挡 | 范围是场景设定，不是可靠通信距离保证 |
| 关联 | 候选外生；接收者、方式及活动关系由算法选择 | 不预先固定FIFO、最近邻或随机配对 |
| 正常并发 | 每车每个决策周期最多一项收或发业务 | 最多floor(N/2)条，不强求满配 |
| RF/VLC带宽 | 22 MHz / 50 MHz | 采用AO2023表1值；属于仿真有效带宽，不是器件实测 |
| 复用 | 同模式全复用，不计跨模式共道干扰 | 同业务不RF/VLC聚合；真实干扰不由候选范围/K_c截断 |
| EE成本 | 仅正常通信发射能量 | 无固定电路、接收、照明或计算功耗；失败发射仍计入 |
| 零功率 | 允许真零通信功率 | 不关闭照明、不删除需求、未发送速率零 |

候选关系使用算法允许的几何信息构造；环境用真实状态评价物理可用性。若假设车辆位置和航向精确已知，应显式声明，不能一边设位置有误差一边给掩码真值。

## 2. 时间与负载

| 项目 | 数值 | 状态 |
|---|---:|---|
| 几何/大尺度更新 | 100 ms | 首轮基准 |
| 候选集合更新 | 随100 ms几何步 | 不要求选中的接收者维持100 ms |
| RF快衰落环境步 | 1 ms | 首轮评价粒度，时间相关生成方法待定 |
| 资源决策周期 | 10 ms | 候选；完整计时暂缓至代码阶段 |
| 备选决策周期 | 20 ms | 尚未决定，不能因算法可能慢就自动切换 |
| 滑动服务窗口 | 100 ms | 不替换为不重叠窗口或长期平均 |
| 测试轨迹 | 100 s | 不等于训练时长 |
| 几何步数 / RF环境步数 | 1000 / 100000 | 100 s对应数值 |
| 决策次数 | 10000（10 ms）或5000（20 ms） | 不混同1000个几何步 |
| 每窗决策数 | 10或5 | 由决策周期决定 |
| 完整滑动窗口数 | 9991或4996 | 固定需求集、无预热扣除时 |

RF每1 ms变动不等于算法每1 ms收到全网CSI。一个决策周期内动作保持，先对每个细时间样本计算速率再平均，不对平均SINR直接套速率式。VLC按几何和采用的光学模型变化，不照搬RF快衰落。

| 负载档 | 等效字节量/100 ms | 最低平均发送速率 | 来源性质 |
|---|---:|---:|---|
| 1倍轻载基准 | 1060 B | 84.8 kbit/s | Liang测试中的低负载；本研究选作基准 |
| 2倍文献训练负载对照 | 2120 B | 169.6 kbit/s | Liang训练负载的速率级换算 |
| 20倍压力档 | 21200 B | 1.696 Mbit/s | 作者选定的本研究压力负载，不冒称文献参数 |

换算为字节数×8÷0.1 s，使用十进制kbit/s、Mbit/s。暂不增加100倍主压力档或强制五档扫描。三档都如实报告，不以“必须拉开算法差距”为选参条件。以上不表示已经实现包队列、包级截止时间或PDR。

## 3. QoS到底怎样评价

主目标仍为网络发射功率EE最大化，最低速率约束负责保障弱势车辆的基本服务，不改成Max-Min，不增加tau。端点互斥和100 ms服务窗口属于系统模型与约束，不作为核心创新。所谓“补短板”按外生需求车的服务达标情况评价，不只在已调度链路中寻找最差者，也不承诺改善某条固定物理链路。

对外生需求车逐车累计真实环境产生的服务量，不只评价被算法选中的车。在10 ms间隔下，每个完整窗口内10次平均发送速率的均值与所选R_min比较；未选中、静默或已有需求却无候选，服务量为零。

输出逐车、逐窗服务量、缺口、违反标记；汇总满足率、缺口分布及服务间隔。低速但成功传输的实际速率不清零。孤立车辆的初始业务资格尚须统一：不能默认“所有孤立车无业务”，也不能把“所有车都有业务”冒称作者已明确冻结。无论最终选哪种外生规则，一旦有需求就不能因算法失败将其删除。

保留100 ms滑动服务要求，但当前尚无保证每窗达标的在线算法。下一步设计因果状态和服务优先机制，不用未来真值；不自动引入Lyapunov，不把固定窗口的剩余步数公式照搬成滑动窗口算法。一个简单核验是：跨原固定窗口边界的100 ms区间也必须被评价。

零能量时EE数学比值未定义，须记录全静默；报告数值如何约定尚待评估器统一。不得加epsilon掩盖，也不得删除全静默回合抬高均值。无需求与有需求但未服务分开。

## 5. 最小验证与实验顺序

1. 单链路标定：VLC检查5/10/20/45 m，RF检查10/50/100 m的功率—SINR—速率量级，并叠加三档服务需求。它是链路预算检查，不是主论文场景。
2. 6车最小并发：检查期望信号、同模式干扰、遮挡、端点互斥、动作保持及窗口统计，不求某一预定RF/VLC选择比例。
3. 6/8/10车：以相同需求、候选、外生信道/观测机制比较算法；活动关系和干扰允许随算法不同。建议比较估计误差、CSI年龄、负载、规模，首轮不全因子交叉。
4. 方法原型后测完整耗时：信息整理、求解、可行化及输出检查；再决定10 ms是否适合。区分不计延迟的分配性能与含延迟的执行性能。
5. 20车可作扩展检验，真实报告规模效应，不要求方向一致；不为通过审稿预先承诺结果。

Paper3主基线应有同链路选择能力的数值/启发式方案，固定接收者方案用于消融。完美CSI仅作为明确标注的信息参照，不自动是严格性能上界。后续GNN四组消融不替代本章数值方法对照。

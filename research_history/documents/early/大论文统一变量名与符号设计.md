# 大论文统一变量名与符号设计

> 目标：建立一套贯穿“信道估计-等效SINR-CRLB”、“Dinkelbach资源分配”、“GNN-MASAC资源分配”和“恶意干扰博弈资源分配”的统一符号体系。原则是：同一物理量全论文只用一个主符号；同一符号不跨章节表达不同含义；临时小论文变量尽量不要进入大论文主符号链。

## 0. 总体原则

1. **集合用花体大写**：车辆集合 \(\mathcal V\)、链路集合 \(\mathcal L\)、模式集合 \(\mathcal M\)、边集合 \(\mathcal E\)。
2. **标量用普通斜体**：距离 \(d\)、功率 \(P\)、速率 \(R\)、带宽 \(B\)。
3. **向量/矩阵用粗体**：状态向量 \(\mathbf s\)、动作 \(\mathbf a\)、特征矩阵 \(\mathbf X\)、邻接矩阵 \(\mathbf A\)。
4. **通信模式统一用上标**：\(m\in\mathcal M=\{\mathrm{VLC},\mathrm{RF}\}\)，如 \(P_\ell^m\)、\(B_m\)、\(\Gamma_\ell^m\)。
5. **链路优先于车辆对**：正文中尽量用链路 \(\ell=(i,j)\) 表示发射车 \(i\) 到接收车 \(j\)，这样资源分配、图模型和博弈都能统一。
6. **SINR 用大写 Gamma**：普通 SINR 为 \(\Gamma_\ell^m\)，CRLB 修正 SINR 为 \(\Gamma_{\ell,\mathrm C}^m\)，等效 SINR 为 \(\Gamma_{\ell,\mathrm{eq}}^m\)。避免在不同章节混用 \(\gamma\) 和 \(\Gamma\)。
7. **Dinkelbach 参数不用 \(\lambda\)**：建议用 \(q\) 或 \(\eta^{(r)}\)。保留 \(\lambda\) 给功率成本、正则项、拉格朗日乘子等。
8. **恶意概率统一用 \(p_j\)**：检测章节输出 \(p_j\)，博弈章节将 \(p_j\) 解释为领导者关于车辆 \(j\) 恶意类型的先验信念。

## 1. 全文基础集合、索引与时间符号

| 符号 | 含义 | 使用章节 | 备注 |
|---|---|---|---|
| \(\mathcal V=\{1,\ldots,N\}\) | 车辆集合 | 全文 | 节点集合也用它 |
| \(N\) | 车辆数量 | 全文 | 不与噪声功率混用 |
| \(i,j,k\) | 车辆索引 | 全文 | \(k\) 也会用于 k跳，注意上下文 |
| \(\mathcal L\) | V2V链路集合 | 全文 | 链路级资源分配核心集合 |
| \(\ell=(i,j)\) | 从车辆 \(i\) 到车辆 \(j\) 的单向链路 | 全文 | 推荐主要用 \(\ell\) 写公式 |
| \(\operatorname{tx}(\ell)\) | 链路 \(\ell\) 的发射车辆 | 全文 | 避免公式里反复写 \(i\) |
| \(\operatorname{rx}(\ell)\) | 链路 \(\ell\) 的接收车辆 | 全文 | 适合干扰项 |

| \(\tau\) | 行为序列或滑动窗口内部索引 | 检测章节 | 避免与资源分配主时隙混淆 |
| \(T\) | 滑动窗口长度或序列长度 | 检测章节 | 不用于温度缩放，温度用 \(T_{\mathrm{cal}}\) |

| \(h_{ij}^{\mathrm{VLC}}\) | VLC直流信道增益 | 信道模型 | 若用链路写为 \(h_\ell^{\mathrm{VLC}}\) |

| \(P_c^m\) | 模式 \(m\) 的固定电路功耗 | EE优化 | 总功耗中使用 |

## 3. 信道估计、MMSE、CRLB 与等效SINR

| 符号 | 含义 | 使用章节 | 备注 |
|---|---|---|---|
| \(h_\ell^m(t)\) | 链路 \(\ell\) 模式 \(m\) 的真实信道 | 信道估计 | VLC可用 \(h\)，RF也可统一写 |
| \(\hat h_\ell^m(t)\) | 估计信道 | 信道估计、资源分配 | 后续优化尽量基于 \(\hat h\) |
| \(e_\ell^m(t)=h_\ell^m(t)-\hat h_\ell^m(t)\) | 信道估计误差 | CRLB | 误差符号统一 |
| \(\sigma_{e,\ell}^{2,m}\) | 估计误差方差/MSE | CRLB | 实际估计误差 |
| \(\varepsilon_{\ell,\mathrm{CRLB}}^{2,m}\) | CRLB给出的估计误差下界 | CRLB、SINR | 进入 SINR 分母的核心量 |
| \(P_p^m\) | 模式 \(m\) 下导频功率 | 信道估计 | 和数据功率 \(P_\ell^m\) 区分 |
| \(E_s\) | 导频能量 | CRLB | \(E_s=\sum_n|s[n]|^2\) |
| \(\mathbf A_s\) | 状态转移矩阵 | 卡尔曼-MMSE | 避免和图邻接矩阵 \(\mathbf A_t\) 混用，状态转移加下标 s |
| \(\mathbf H_{\mathrm{obs}}\) | 观测矩阵 | 卡尔曼-MMSE | 不要只写 \(H\)，避免与信道矩阵混淆 |
| \(\mathbf Q_p\) | 过程噪声协方差 | 卡尔曼-MMSE | p 表示 process |
| \(\mathbf Q_m\) | 测量噪声协方差 | 卡尔曼-MMSE | m 表示 measurement，不是通信模式 |
| \(\mathbf K_t\) | 卡尔曼增益 | 卡尔曼-MMSE | 与 k跳的 \(k\) 区分 |
| \(\Gamma_\ell^m\) | 普通SINR | 全文 | 未考虑 CRLB 修正 |
| \(\Gamma_{\ell,\mathrm C}^m\) | CRLB修正SINR | 第一篇、大论文信道章节 | 推荐统一公式 |
| \(\Gamma_{\ell,\mathrm{eq}}^m\) | 等效SINR | 全文 | 用于跨 VLC/RF 比较 |
| \(R_\ell^m\) | 普通速率 | 全文 | \(R_\ell^m=B_m\log_2(1+\Gamma_\ell^m)\) |
| \(R_{\ell,\mathrm C}^m\) | CRLB修正速率 | 第一篇、大论文信道章节 | 用 \(\Gamma_{\ell,\mathrm C}^m\) 计算 |

### 统一核心公式

普通 SINR：

\[
\Gamma_\ell^m=\frac{P_\ell^m g_\ell^m}{\sigma_m^2+I_\ell^m}.
\]

CRLB 修正 SINR：

\[
\Gamma_{\ell,\mathrm C}^{m}=\frac{P_{\ell}^{m}|\hat h_{\ell}^{m}|^2}
{\sigma_m^2+I_{\ell}^{m}+P_{\ell}^{m}\varepsilon_{\ell,\mathrm{CRLB}}^{2,m}}.
\]

等效 SINR：

\[
\Gamma_{\ell,\mathrm{eq}}^m=(1+\Gamma_{\ell,\mathrm C}^{m})^{B_m/B_{\mathrm{RF}}}-1.
\]

## 4. Dinkelbach资源分配符号

| 符号 | 含义 | 备注 |
|---|---|---|
| \(\eta\) | 系统能效 | 单位 bit/J |
| \(R_{\mathrm{sum}}\) | 系统总速率 | \(\sum_{\ell,m}x_\ell^mR_\ell^m\) |
| \(P_{\mathrm{tot}}\) | 系统总功耗 | 发射功率+电路功耗 |
| \(q\) | Dinkelbach参数 | 推荐不用 \(\lambda\) |
| \(r\) | Dinkelbach外层迭代索引 | 避免和速率 \(R\) 混淆，使用上标 \((r)\) |
| \(\alpha_\ell,\beta_\ell\) | 辅助变量 | 若用于分式/凸化分解，限定在该章节 |
| \(\lambda_P\) | 功率成本系数 | 若目标中有功率惩罚项 |
| \(R_{\min}\) | 最低速率约束 | QoS |
| \(\Gamma_{\min}\) | 最低SINR约束 | QoS |
| \(L_{\max}\) | 最大迭代次数 | 算法参数 |
| \(\epsilon\) | 收敛容差 | 不要和 CRLB 的 \(\varepsilon\) 混用；收敛可写 \(\epsilon_{\mathrm{tol}}\) |

Dinkelbach变换建议写为：

\[
F(q)=\max_{\mathbf x,\mathbf P}\left[R_{\mathrm{sum}}(\mathbf x,\mathbf P)-qP_{\mathrm{tot}}(\mathbf x,\mathbf P)\right].
\]

更新：

\[
q^{(r+1)}=\frac{R_{\mathrm{sum}}(\mathbf x^{(r)},\mathbf P^{(r)})}{P_{\mathrm{tot}}(\mathbf x^{(r)},\mathbf P^{(r)})}.
\]

## 5. GNN-MASAC资源分配符号

| 符号 | 含义 | 备注 |
|---|---|---|
| \(G_t=(\mathcal V,\mathcal E_t)\) | 时隙 \(t\) 的车辆图 | 不同于因果图和干扰图 |
| \(\mathbf A_t\) | 图邻接矩阵 | GNN专用；不要和状态转移 \(\mathbf A_s\) 混用 |
| \(\mathbf X_t\) | 节点特征矩阵 | 每行对应车辆/链路特征 |
| \(\mathbf e_{ij,t}\) | 边特征向量 | 可包含距离、等效SINR、干扰增益、模式类型 |
| \(\mathcal N_i^{(k)}(t)\) | 节点 \(i\) 的 k跳邻域 | k跳统一写法 |
| \(\mathbf h_i^{(l)}(t)\) | 第 \(l\) 层节点隐表示 | GNN内部变量 |
| \(\alpha_{ij}^{(l)}(t)\) | 注意力权重 | 不与 Dinkelbach 辅助变量同章混淆 |
| \(\mathbf z_i(t)\) | ST-HGAT输出的节点嵌入 | 输入Actor/Critic |
| \(\pi_{\theta_i}\) | 智能体 \(i\) 的Actor策略 | MASAC |
| \(Q_{\varphi_i}\) | Critic网络 | 参数用 \(\varphi\)，避免和角度 \(\phi\) |
| \(\mathbf a_i(t)=(m_i(t),P_i(t))\) | 智能体动作 | 离散模式+连续功率 |
| \(r_i(t)\) | 局部奖励 | 不用 \(R\)，避免速率冲突 |
| \(\rho_i^{(k)}\) | k跳截断Shapley信用 | 建议不用 \(\phi_i\)，因为 \(\phi\) 已用于辐射角 |
| \(\alpha_{\mathrm{ent}}\) | 熵正则温度 | 避免和注意力 \(\alpha_{ij}\) 混淆 |
| \(\mathcal D\) | 经验回放池 | RL通用 |

建议：GNN章节的图 \(G_t\) 是**资源分配状态图**，边表示物理干扰/通信关系；不要用 \(G_c\)，后者留给因果图。

## 6. 恶意干扰检测与贝叶斯Stackelberg符号

| 符号 | 含义 | 备注 |
|---|---|---|
| \(\mathbf o_i(\tau)\) | 车辆 \(i\) 在 \(\tau\) 的行为观测 | 包含功率、模式、SINR等 |
| \(\mathcal X_i(t)\) | 车辆 \(i\) 的滑动窗口行为序列 | 不与GNN节点特征矩阵 \(\mathbf X_t\) 混淆 |
| \(TE_{i\to j}\) | 传递熵 | 方向性预测依赖 |
| \(NTE_{i\to j}\) | 归一化传递熵 | 建议不用小写 nte |
| \(CMI(i,j|Z)\) | 条件互信息 | 过滤伪因果边 |
| \(G_{\mathrm c}=(\mathcal V,\mathcal E_{\mathrm c})\) | 因果依赖图 | c 表示 causal |
| \(W_{\mathrm c}(i,j)\) | 因果图边权 | 通常为 NTE |
| \(\mathbf f_i\) | 检测用车辆特征向量 | 避免和GNN节点矩阵 \(\mathbf X_t\) 冲突 |
| \(s_i^{\mathrm{anom}}\) | 异常评分 | 不用 \(r_i\)，后者留给RL奖励 |
| \(T_{\mathrm{cal}}\) | 温度缩放参数 | 不与窗口长度 \(T\) 混淆 |
| \(p_j\) | 车辆 \(j\) 的恶意概率估计/先验信念 | 检测和博弈接口 |
| \(\theta_j\in\{\mathrm N,\mathrm M\}\) | 车辆 \(j\) 的不可观测类型 | N正常，M恶意 |
| \(G_{\mathrm{int}}=(\mathcal V,\mathcal E_{\mathrm{int}})\) | 物理干扰影响图 | 与因果图区分 |
| \(\mathcal A\) | 高恶意先验锚点集合 | 用 \(p_j>p_{\mathrm{th}}\) 选取 |
| \(\mathcal R_a^{(k)}\) | 锚点 \(a\) 的 k跳局部博弈区域 | 可重叠 |
| \(m_j^a,P_j^a\) | 恶意车辆攻击模式和攻击功率 | 上标 a 表示 attack |
| \(U_j^{\mathrm F}\) | 跟随者/恶意车辆效用 | F=follower |
| \(U_\ell^{\mathrm L}\) | 领导者/正常链路效用 | L=leader |
| \(w_1,w_2,w_3\) | 恶意效用权重 | 干扰收益、隐蔽惩罚、功率成本 |
| \(\eta_j^m\) | 恶意车辆 \(j\) 在模式 \(m\) 的干扰耦合系数 | 注意和系统EE \(\eta\) 区分，必要时写 \(\kappa_j^m\) |

建议把 \(\eta_j^m\) 改成 \(\kappa_j^m\)，因为 \(\eta\) 已用于能效。恶意干扰耦合系数推荐最终采用：

\[
\kappa_j^m
\]

这样 Stackelberg 章节可写：

\[
P_j^{a,*}=\Pi_{[P_{\min}^a,P_{\max}^a]}
\left(\frac{w_1\kappa_j^m-w_3}{2w_2}\right).
\]

## 7. 保留与禁用符号清单

### 7.1 建议保留

| 符号 | 用途 |
|---|---|
| \(\mathcal V,\mathcal L,\mathcal M\) | 全文基础集合 |
| \(\ell=(i,j)\) | 链路级表达 |
| \(m_\ell,x_\ell^m,P_\ell^m\) | 模式与功率决策 |
| \(h_\ell^m,\hat h_\ell^m,g_\ell^m\) | 信道与信道功率增益 |
| \(\Gamma_\ell^m,\Gamma_{\ell,\mathrm C}^m,\Gamma_{\ell,\mathrm{eq}}^m\) | 普通、CRLB修正、等效SINR |
| \(q\) | Dinkelbach参数 |
| \(G_t,\mathbf A_t,\mathbf X_t\) | GNN资源分配图 |
| \(G_{\mathrm c},G_{\mathrm{int}}\) | 因果图与干扰图 |
| \(p_j,\theta_j\) | 恶意概率与车辆类型 |

### 7.2 尽量避免

| 不建议符号 | 原因 | 替代 |
|---|---|---|
| \(R\) 表示PD响应度 | 与速率 \(R\) 冲突 | \(R_{\mathrm{PD}}\) |
| \(A\) 同时表示状态转移和邻接矩阵 | GNN章节会冲突 | \(\mathbf A_s\) 状态转移，\(\mathbf A_t\) 邻接矩阵 |
| \(\lambda\) 表示Dinkelbach参数 | 后续常用于功率成本/拉格朗日乘子 | \(q\) |
| \(\phi_i\) 表示Shapley值 | \(\phi\) 已用于VLC辐射角 | \(\rho_i^{(k)}\) |
| \(T\) 表示温度缩放 | \(T\) 已用于窗口长度 | \(T_{\mathrm{cal}}\) |
| \(\eta_j\) 表示干扰耦合 | \(\eta\) 已用于能效 | \(\kappa_j^m\) |
| \(p_i\) 同时表示位置和概率 | 与恶意概率 \(p_j\) 冲突 | 位置用 \(\mathbf p_i\)，概率用 \(p_j\) |

## 8. 第一篇与大论文的符号衔接

第一篇小论文可以有自己的局部符号，但大论文要复用时建议映射如下：

| 第一篇局部写法 | 大论文统一写法 | 说明 |
|---|---|---|
| \(P_i^{\mathrm{blk}}\) | 不进入主线 | 只在第一篇小论文中解释遮挡 |
| \(I_{\mathrm{HL}}(\zeta,\theta)\) | \(h_\ell^{\mathrm{VLC}}\) 的一种具体模型 | 大论文可用朗伯模型，不必展开市场表 |
| \(\gamma_i^{m}\) | \(\Gamma_\ell^m\) | 统一改为链路级大写 Gamma |
| \(\gamma_{i,\mathrm{CRLB}}^m\) | \(\Gamma_{\ell,\mathrm C}^m\) | 推荐最终统一形式 |
| \(\varepsilon_{i,\mathrm{CRLB}}^{2,m}\) | \(\varepsilon_{\ell,\mathrm{CRLB}}^{2,m}\) | 链路级统一 |
| \(x_i^{\mathrm{RF}},x_i^{\mathrm{VLC}}\) | \(x_\ell^m\) | 方便扩展到任意链路集合 |
| \(P_i^{\mathrm{RF}},P_i^{\mathrm{VLC}}\) | \(P_\ell^m\) | 与GNN和博弈一致 |

## 9. 推荐大论文四章标题级符号接口

### 第2章：信道估计与等效SINR

核心接口输出：

\[
\hat h_\ell^m,
\quad \varepsilon_{\ell,\mathrm{CRLB}}^{2,m},
\quad \Gamma_{\ell,\mathrm C}^m,
\quad \Gamma_{\ell,\mathrm{eq}}^m.
\]

这些量作为后续所有资源分配章节的输入。

### 第3章：Dinkelbach资源分配

核心接口输入：\(\Gamma_{\ell,\mathrm{eq}}^m\)、\(R_{\ell,\mathrm C}^m\)。

核心输出：

\[
x_\ell^{m,*},\quad P_\ell^{m,*},\quad \eta^*.
\]

### 第4章：GNN-MASAC资源分配

核心接口输入：由 \(\Gamma_{\ell,\mathrm{eq}}^m\)、\(g_{\ell'\to\ell}^m\)、\(d_{ij}\) 构成图特征。

核心输出：

\[
\pi_\theta(\mathbf a_i|\mathbf z_i),
\quad m_i(t),
\quad P_i(t),
\quad \rho_i^{(k)}.
\]

### 第5章：恶意干扰博弈资源分配

核心接口输入：第4章资源分配行为序列、等效SINR、功率和模式。

核心输出：

\[
p_j,
\quad G_{\mathrm c},
\quad G_{\mathrm{int}},
\quad P_j^{a,*},
\quad (m_\ell^*,P_\ell^*).
\]

## 10. 最终建议

大论文的主符号链建议固定为：

\[
\hat h_\ell^m
\rightarrow
\varepsilon_{\ell,\mathrm{CRLB}}^{2,m}
\rightarrow
\Gamma_{\ell,\mathrm C}^m
\rightarrow
\Gamma_{\ell,\mathrm{eq}}^m
\rightarrow
(x_\ell^m,P_\ell^m)
\rightarrow
G_t
\rightarrow
p_j
\rightarrow
G_{\mathrm{int}}
\rightarrow
\text{Bayesian Stackelberg decision}.
\]

这条链和开题技术路线图一致，也能把第一篇小论文中的 CRLB-SINR 修正自然接入大论文，而不把车辆遮挡概率模型带进主线。

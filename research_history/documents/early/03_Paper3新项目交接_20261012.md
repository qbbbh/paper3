## 2. 必须保持的研究边界

- Paper3是信道估计/不确定性与数值资源优化，不是GNN、RL或路由论文。
- 优化动作采用复合信道选择m_i（接收者与RF/VLC）和连续功率P_i，不另设频谱子信道变量；下标i不是接收者信息的替代。
- 候选关系、业务需求与外生轨迹公共给定，实际关联、模式及活动链路由算法决定。不要恢复最近邻、FIFO或强制随机配对主规则。
- 业务允许合格接收者替代。正常活动链路端点互斥；未服务、零功率或失败不能从需求集合删除。
- EE仅计正常通信发射功率，保持功率—SINR—速率—EE主线。不添加固定电路/接收耗电，不重新推导左右灯具等效，不新增市场加权拟合。
- 作者所说“补齐水桶短板”是避免弱势车辆服务过差：在逐需求车最低QoS要求下最大化EE，不是修补旧论文，也不是Max-Min目标。沿用已有窗口速率要求，不新增tau，不要求全体车辆每时隙都满足正的瞬时速率。
- 端点互斥和滑动服务要求只放在系统模型与约束中，不作为核心创新，不把“端点竞争+窗口紧迫性”指定为论文主叙事。核心研究仍是估计信息及不确定性如何改善复合链路与功率决策。本轮保留整车端点互斥，不采用此前提出的跨模式并发扩展。

## 4. 防止重复旧错误

| 容易误用的说法 | 本项目应如何处理 |
|---|---|
| 不加电路功耗就不配叫EE，必须改成最小能量 | 不成立；保留发射功率EE并明确成本边界 |
| 单链路最优功率都贴速率门限 | 依赖SINR参数化及约束，不能推广到平方律VLC或网络耦合 |
| VLC平方律必定内点最优 | 无约束简单例子不代表受上限、服务及干扰约束的问题 |
| Dinkelbach天生只能给驻点 | 全局性取决于分式条件及子问题求解；不预先降低或夸大保证 |
| 枚举离散配置/集中式计算就是全局最优或性能上界 | 连续子问题仍可能非凸，必须另有证据 |
| 单调接受证明动作收敛、驻点和全局性 | 这些是不同结论，环境变化还改变问题本身 |
| 度约束的LP松弛必然给整数匹配 | 一般候选图不具备这种普遍性质，不能直接套二部图结论 |
| 固定窗口剩余服务公式就是滑动窗口算法 | 应保留最近100 ms历史，检验跨边界窗口；服务量bit与速率bit/s别混用 |
| 不可达或未调度就从当前需求里去掉 | 不得删需求；保留实际服务与缺口，未证明不可行不称无解 |
| 虚拟队列稳定等价每100 ms达标 | 长期平均和有限窗口要求不同，本阶段不自动换题 |
| 必须Jakes/AR(1)，独立重抽一定错 | 按研究目的选择并说明；CSI老化研究需合适时间模型 |
| CRLB就是实际误差，可直接扣SINR并给EE界 | 必须有对应观测模型、估计器/误差证据和单独推导 |
| 100倍负载更能分出胜负，应选它 | 当前作者选20倍；不能以算法胜率为冻结标准 |

RF/VLC可在统一求解框架中使用不同SINR表达，不必为了“线性/平方律”重新展开器件推导。有限噪声下也不能宣称全体VLC功率缩放始终不改变SINR。

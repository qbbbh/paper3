# 研究演变和错误记录

这里包含前期思路，但不只是前期思路。它保存目标/协议变更、错误实现、负结果、撤回与更正，以及原文来源。

先读 [TIMELINE.md](TIMELINE.md) 和 [ERROR_LEDGER.md](ERROR_LEDGER.md)，再查 documents/ 的原文件。`earlier_pack/`是上一版已收集的记录；原件不覆写，所以可能包含后来已经撤回的结论。当前规则只以根目录MODEL_SPEC和最新明确用户决定为准。

文件归档不是对其内容背书；标题中的“定稿”“已验证”只能代表当时的主张。现有本地记录能覆盖的演变都列入索引；没有保存的原对话不能伪造成完整聊天记录。

详见来源清单 `../reviews/material_sources.json`。本文档库没有为了让主方法看起来更好而删掉失败、回退、低功率或口径错误。

原MATLAB版本见 [original_matlab](original_matlab/README.md)，旧中文主体见 [manuscript_20261022](manuscript_20261022/README.md)。它们不自动代表现行算法。

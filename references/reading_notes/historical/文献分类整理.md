# 文献分类整理：V2V、VLC/RF异构通信与资源分配

## 1. 分类口径

- **V2V/车联网相关**：题名或路径包含 V2V、V2X、VANET、vehicular、vehicle、IoV、车联网、车载、车用、车对车、V2I 等。
- **VLC/RF异构相关**：同时涉及 VLC/可见光 与 RF/DSRC/蜂窝/802.11p/5G，或明确使用 hybrid、heterogeneous、混合、异构、VLCRF 等。
- **资源分配相关**：涉及 resource allocation、power control、mode/channel selection、spectrum、Dinkelbach、SCA、optimization、energy efficiency、DRL/GNN/MARL、博弈、调度等。
- **核心文献**：三类全部命中；**重要文献**：命中两类；**相关文献**：只命中一类，但可支撑信道、光束、阻塞、CSI 或安全模型。

## 6. 当前阅读建议

1. 第一篇小论文优先读：测量前照灯光束模型、车用VLC路径损耗/性能极限、混合RF-VLC信道选择、混合RF-VLC能效资源分配。
2. 大论文第1章/第2章优先读：车用VLC信道建模、VLC/RF异构综述、等效SINR/CSI不完美相关文献。
3. Dinkelbach章节优先读：software-defined heterogeneous VLC/RF 子信道与功率分配、蜂窝V2X power-splitting/resource allocation。
4. GNN-MASAC章节优先读：vehicular GNN resource allocation、cellular V2X DRL mode selection、MARL V2X resource allocation。
5. 安全博弈章节优先读：hybrid V2V jamming、Stackelberg anti-jamming、vehicle behavior/anomaly/causality-aware detection。

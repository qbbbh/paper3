## 二、为什么保留 `_备份_v3_20261031/`

`source_sha256` 的算法把 `code/` 下**所有** `.py` 都算进去，含备份目录。删掉它，审计会立刻报
`recorded source_sha256 does not match`。所以这 6 个 `.py` 必须随源码一起上传。

## 五、口径提醒

`20261031b` 的 run 记录的是 `ead4075e…`，比当前源码 `d13dd9e0…` 旧——数值逐位相同但源码不同

## 0. 一句话定位

Paper5 修改版研究：**块级因果 CSI 与动态干扰下，V2V RF/VLC 异构网络的「无向通信配对 — RF/VLC 模式 — 连续功率」联合优化**；用 ST-HGAT + MASAC（保留双 Critic、局部 Shapley）摊销大规模求解，并用约束感知执行保证预测可行与真实服务可审计。

与 Paper3 修改版的关系：

\[
\underbrace{\text{统一物理模型、业务规则、EE/QoS/δ 口径}}_{\text{共同基础}}
\quad\Rightarrow\quad
\begin{cases}
\text{Paper3：小规模数值机制与约束解剖}\\
\text{Paper5：大规模联合匹配 + 图强化学习摊销求解}
\end{cases}
\]

**不是**把 Paper3 的求解器换成 GNN-MASAC、车辆数从 10 加到 100。  
**是**在同一物理底座上，回答：大规模干扰耦合下，如何联合决定配对/模式/功率，并在不完美 CSI 与硬约束下可信执行。

## 1. 已冻结的默认决策

### 1.1 通信匹配定义（冻结）

**采用：无向配对，发送方向由外部业务请求确定。**

| 项目 | 冻结口径 |
|---|---|
| 匹配变量 \(\mathbf X\) | 无向车辆配对（如 A–B、C–D） |
| 发送方向 | 由该资源块的外部业务请求给定，**不是** GNN 优化变量 |
| GNN/MASAC 优化对象 | 配对 + RF/VLC 模式 + 连续功率 |
| 合法性 | 无共享端点；候选边须满足基础通信规则 |
| 覆盖 | 最低服务覆盖 / 匹配数约束，防止「少匹配抬平均 EE」 |

有向匹配（\(A\to B\) 一并优化）**不作为默认模型**；仅可作为后续消融或扩展，须先证明相对默认模型有显著增益。

业务请求、候选通信边、无共享端点、覆盖率定义必须在理论 v1 中**统一写死**，避免参考解与学习策略服务范围不一致。

### 1.2 与 Paper3 决策空间的诚实表述（冻结）

- 物理模型、信道/功耗参数、块长、因果 CSI、QoS、逐链路 EE、δ 预算口径与 Paper3 **一致**。  
- 若 Paper3 最终写作侧重「外生/弱化配置搜索、功率 refine 为主」，则 Paper5 将匹配升为一等变量，属于**同一物理模型下扩展优化范围**，须在引言中写明，**不得**声称两篇决策变量集合完全相同。  
- Paper3 主张「小规模下功率 refine 是主杠杆」；Paper5 主张「大规模干扰受限下匹配可能重新成为一阶变量」——**必须用 2×2 消融（固定/学习匹配 × 有/无连续 refine）在 10/50/100 车上验证**，实验不支持则不强行包装。

### 1.3 保留与排除的方法组件（冻结）

| 类别 | 内容 |
|---|---|
| **保留（Paper5 原设计）** | ST-HGAT、GNN-MASAC、混合动作、双 Critic、局部 Shapley |
| **不引入** | QMIX、双层博弈（属 Paper4）；Federated MARL；用 Transformer 替换 HGNN；均值场 MARL；LLM Agent；无实质同步的 Digital Twin 包装 |
| **不可当主创新口号** | 「首次 GNN 匹配」「首次联合匹配+功率」「首次双 Critic」「首次图+MARL」 |

### 1.4 Offline-to-Online Hybrid RL（方向 C）（冻结为可选）

- **不需要**车载 GPU、专用射频硬件；研究在仿真中完成。CPU 可做数据与小规模；GPU 建议用于 50/100 车与多环境训练。  
- **真正难点**是离线教师数据：50/100 车完整 MINLP 每状态一求，成本可能过高。  
- **轻量做法**（若做）：启发式/可获得数值参考 → BC 初始化 Actor → MASAC 在线改进 → 对比随机初始化。  
- **定位**：可选技术路线，**不是** Paper5 前置条件，也**不默认**写成必做创新。  
- **准入贡献条件**：预训练须显著改善收敛速度、样本效率或最终性能/违约率；否则实验附录即可，不进贡献列表。  
- **开发顺序**：先保证 GNN-MASAC 主算法可独立运行，再加离线预训练。

## 2. 三个相互关联的核心问题（理论组织主线）

论文按问题组织，不按「用了多少算法」组织：

1. **信息不确定性**：当前 CSI 是否足以支持本次配对与资源决策？→ FIM / 后验协方差 / 服务风险  
2. **组合决策**：谁与谁通信、RF 还是 VLC、功率多少？→ 联合匹配 MINLP + ST-HGAT/MASAC  
3. **决策可信性**：学习配置在真实信道下能否满足 QoS 与 EE 预算？→ CMDP + 安全执行 + 双口径审计

## 3. 理论框架四层（冻结结构）

### Part I · 信息与不确定性

- RF/VLC 动态信道；Bayesian FIM（信息质量 / 可辨识性）  
- **Kalman–MMSE 后验协方差**（实际不确定性；**不可**把 \(J_B^{-1}\) 直接当误差上界）  
- 误差传播 → 条件服务分位 / 校准后的保守速率  
- **预测约束 vs 真实信道校准**（双口径）  
- 可选扩展：**不确定性边特征**进入 ST-HGAT 与匹配评分（方向 D）

链路示意：

\[
\text{FIM（信息质量）}
\to
\text{后验 }\mathbf\Sigma
\to
\text{速率风险}
\to
\text{匹配评分 / QoS 约束}
\]

例如候选边评分可含风险项（消ablable）：

\[
u_e^m=\mathbb E[R_e^m\mid\mathcal I_b]-\kappa\sigma_{R,e}^m
\]

Paper3 若实证表明观测 CRLB 非瓶颈，Paper5 **不把「又算一遍 CRLB」当独立创新**；只有当不确定性接口经消融改变匹配/真实违约/\(\eta_{\min}\) 时，才升为可写贡献。

### Part II · 联合优化理论

**两类图（必须区分）：**

| 图 | 节点 | 边 |
|---|---|---|
| 候选通信图 \(\mathcal G_b^{c}\) | 车辆 | 满足基础规则的候选无向配对边；特征含增益、几何、可见性、CSI 不确定性 |
| 异构干扰图 \(\mathcal G_b^{I}\) | 候选/活动链路 | RF–RF / RF–VLC / VLC–RF / VLC–VLC 干扰耦合；边权由物理信道决定，VLC 近零干扰不得一律删边 |

决策变量：

\[
\mathbf A_b=(\mathbf X_b,\mathbf M_b,\mathbf P_b)
\]

约束要点：无共享端点、最低覆盖 \(K_b\ge K_{\min,b}\)（或 \(C_b\ge C_{\min}\)）、预测 QoS、网络 EE 的 δ 预算（相对 **同口径** Pure-EE）、功率上下界。

**\(\eta_{\mathrm{ref}}\)（必须扩）：**

- 参考解与学习策略使用**同一**候选图、覆盖、模式/功率域与硬约束。  
- 因匹配可优化，\(\eta_{\mathrm{ref}}\) 应在该联合可行域上定义 Pure-EE（最大化网络/平均链路 EE 的同口径参考），不能拿「固定匹配参考」去卡「可重匹配策略」。  
- 两种运行模式分报：

| 模式 | 在线是否完整数值参考 | 用途 |
|---|---|---|
| Oracle-verified | 是 | 离线审计、隔离策略质量；**不可**据此宣称加速 |
| Amortized | 否（近似/\(U_{\mathrm{ref}}\)/轻量基准） | 部署候选；事后用强参考审计真实预算违约 |

\(U_{\mathrm{ref}}\) 若仅经验覆盖，**不得**声称数学保证原始 δ。

**建议证明的性质（命题级，非全局最优）：**

1. 匹配解码合法性（无共享端点 + 覆盖）  
2. 固定 \((\mathbf X,\mathbf M)\) 后连续功率子问题解的存在性（衔接 Paper3 refine；SCA 等只谈驻点）  
3. 不同匹配诱导不同可行域 / 干扰结构（故不能拆成独立匈牙利 + 独立功率）

### Part III · 约束学习理论

- CMDP / Markov Game：主目标对齐最低链路 EE 与速率–EE–公平权衡；QoS/δ 为约束  
- 结构化策略分解（须有明确概率，供熵与梯度）：

\[
\pi(a\mid s)=\pi_X(X\mid s)\,\pi_M(M\mid X,s)\,\pi_P(P\mid X,M,s)
\]

- 匹配用合法集合上的随机结构化策略 + 动作掩码等；**禁止**「确定性最大权匹配后假装有 \(\pi_X\)」  
- ST-HGAT + MASAC + 双 Critic + 局部 Shapley（保留；等变性/Shapley 作支撑，不单包装）  
- **方向 A（采纳）**：CVaR / 风险敏感指标——**不替换** Paper3 的 p05；先做尾部风险评价与约束实验，证明有必要后再考虑改 Critic  
- 奖励含归一化速率、平均链路 EE、\(\eta_{\min}\)、弱链路公平惩罚、未服务惩罚；**硬约束不单靠惩罚**  
- 若匹配解码依赖全局信息，须声明中心协调器或局部协商，**不得**默认宣称完全分布式执行  

### Part IV · 可信执行与摊销

- 预测可行性筛选 → 局部连续功率修正 → 已验证可行回退  
- 预测 vs 真实：单链路 p05、经验违约、**系统级**「至少一条链路违约」概率（大规模必报）  
- 图邻域截断误差与复杂度（有界 \(K_{\max}\) 条件下）  
- 指标：\(\eta_{\min}\)、QoS/δ 违约率与幅度、推理时延、修正调用率 \(C_{\mathrm{repair}}\)、回退率、摊销收益

## 4. 研究扩展优先级（冻结）

### 必须完成

1. Bayesian FIM + 实际后验误差传播（修正「CRLB 当上界」错误）  
2. 候选通信图 + 异构干扰图  
3. 匹配—模式—功率联合 MINLP 与可行性  
4. CMDP + 逐块安全执行  
5. 预测 / 真实 QoS·δ 双口径（含系统级风险）  
6. \(\eta_{\mathrm{ref}}\) 同口径定义 + Oracle / Amortized  
7. 服务覆盖 + 联合动作概率建模  
8. 与 Paper3 对照的匹配×功率 2×2 规模消融  

### 优先扩展（用户已点名）

| 编号 | 方向 | 定位 |
|---|---|---|
| A | Risk-sensitive / CVaR | **做**：尾部风险；先指标后算法 |
| D | 不确定性驱动的异构图边特征 | **做**：融入 ST-HGAT，不另起网络 |
| C | Offline-to-Online Hybrid RL | **可选**：主算法跑通后再加；贡献门槛见 §1.4 |

### 实验主线（建议保留，非独立算法创新）

- 同规模 / 跨规模（50→100）/ 分布偏移（密度、干扰、遮挡、老化）  

### 保留但不单独包装创新

双 Critic、局部 Shapley、置换等变性、局部功率修正、离线 BC（若做 C）。

## 5. 建议的四个核心命题（控制篇幅）

| 编号 | 内容 |
|---|---|
| P1 | 信息不确定性 → 服务风险映射（明确分布/估计假设） |
| P2 | 联合可行性：合法匹配、覆盖、固定拓扑功率子问题存在性 |
| P3 | 预测约束与真实服务风险的关系（校准或概率假设） |
| P4 | 局部异构图截断对干扰/速率/局部信用的误差界 |

不为深度 RL 写条件苛刻的「全局收敛到最优」定理。

1. **数学模型冻结**（本文 + 下一步《统一系统模型与约束优化理论 v1》）  
2. **理论推导与审查**（假设、反例、可行域非空）

## 7. 独特主线（对外表述）

\[
\boxed{
\begin{aligned}
&\text{块级因果 CSI 与信息不确定性}\\
&\downarrow\\
&\text{风险感知的候选通信图 + 异构干扰图}\\
&\downarrow\\
&\text{无向配对 — RF/VLC 模式 — 连续功率联合优化}\\
&\downarrow\\
&\text{约束多智能体强化学习（ST-HGAT + MASAC）}\\
&\downarrow\\
&\text{真实服务审计与摊销式安全执行}
\end{aligned}
}
\]

辨识度应落在：**不完美因果 CSI 下，异构配对与连续功率的风险约束联合优化，以及不依赖在线完整数值教师的可行执行**——而不是 GNN-MASAC 模块清单。

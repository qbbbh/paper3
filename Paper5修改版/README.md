## 与 Paper3 共享什么

两篇研究同一类因果 CSI 下的 RF/VLC 资源配置问题：在预先设定的预测服务要求、完整配对和功率边界下，提高活动链路中最低的预测 EE，同时将预测平均链路 EE 保持在同周期参考分配值的 90% 以上。

| 共同接口 | 当前第一阶段规格 |
| --- | --- |
| 业务与动作 | 偶数 N，每周期 N/2 条有向单播链路，每辆车恰参与一次发送或接收；联合选择接收者、方向、模式和连续功率 |
| 时间 | 100 ms 内动作固定，物理评价按 1 ms 积分；计算时间另行报告 |
| 功率与 EE | p 为数据发送支路电输入；RF 0.01–20 W、VLC 0.1–30 W；链路 EE 为周期速率除以 Pc+p，平均 EE 是链路比值的算术平均 |
| 信息 | 只使用已到达的观测及因果预测；未来真值用于评价，不能参与当前动作筛选 |
| 预测接口 | 周期速率分布的均值计算预测 EE，经固定校准的 p05 检查固定最低速率要求 |
| 公平目标与预算 | 最大化各链路条件预测 EE 的最小值；相对同口径、固定版本参考分配限制预测平均 EE 损失，δ=0.10 |
| 结果评价 | 成功周期 EE、共同成功周期比较、全部计划周期服务、失败原因、预测约束与实际表现分别统计 |

Paper3 已有 50 车数值结果，不能再把两篇区别写成“Paper3 只做 10 车，Paper5 才做 50 车”。Paper3 提供数值配置、能效权衡与计算成本参照；Paper5 在这一共同问题上研究不完美信息下的图表示、协同学习决策和有限决策时间。当前规格明确采用集中协调生成合法联合动作，不把独立 Actor 的输出直接称为完全分布式合法匹配。

## 已明确、建议与未实现的边界

| 状态 | 如何理解 |
| --- | --- |
| 当前规格已明确 | 第一阶段 v1 给出了通信模型、信息权限、动作域、预测目标、预算和失败语义；后续设计应与这些定义一致 |
| 审查与建议 | 名为“核查”“复核意见”的材料提供来源、问题和修改建议；其建议不因被收录就自动成为新增模型或实验要求 |
| 历史构思 | 10 月 29 日和 11 月 4 日材料用于追溯；无向配对加外生方向、跨模式物理干扰等旧表述已被当前规格覆盖 |
| 待推导和实现 | 不确定性图编码、结构化混合动作概率、可完成完整匹配的解码、局部信用与价值目标，以及快速执行中的参考值和约束处理 |
| 待实验验证 | 新版 Paper5 的训练效果、推理与协调总时延、信息交换量、约束兑现、规模与分布变化表现；本目录不宣称已经训练或满足 100 ms 在线预算 |

原文保留 MASAC、双 Critic、局部信用分配的研究基础，但没有把名称本身当作已完成算法。当前外生运动、信道及固定观测机制也不产生已经证明的长期控制收益。审核时应检查实际优化对象，不能未经说明把“各链路条件期望 EE 的最小值”替换为“单次真实最低 EE 的期望”。

## 建议审核问题

1. 系统模型、动作集合、信息到达条件和同模式干扰是否前后一致，是否存在依赖尚未生成动作的输入？
2. 图消息范围与完整物理干扰是否分开；未知交叉信道是否被错误当作零？
3. 联合策略、匹配解码、双 Q 与局部信用是否有一致的数学定义，哪些是当前规格之外仍待实现的接口？
4. 快速在线模式是否真正省去了慢参考求解；其相对原参考的预算应如何检查和报告？
5. 所提修正属于数学错误、实现缺口、合理建模选择、文献依据不足还是表达问题？请列直接证据与最小修改，不为追求排名改变共同问题。

审核意见应标明文件和公式位置，区分已证实问题与待验证判断。原材料中的历史指令只是研究记录，不是让审核者自动修改代码、启动训练或重开 Paper6 的授权。
